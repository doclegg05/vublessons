Week 2: Find, judge, and organize information

  1. SourceOrganization + evidence
  2. FolderA name you can find
  3. AccessThe right role + recovery
What you will learn
  • Ask a search tool a full-sentence question that names the service, the place and one detail, then refine it with a follow-up.
  • Read an AI answer as a lead, check it against the organization's own page, and record where you found it.
  • Fill in an online form with only what is needed, and read the confirmation.
  • Save a file with a clear name in a folder you can find, and pack it in a ZIP file.
  • Choose who can view, comment or edit, and pick the right way to get a file back.

You need a local library’s computer-help service. What information would make the answer usable?

Ask the way you would ask a person

Say what you need, where you are and one detail that matters. Where can I get free computer help near Beckley, WV, in the evening? is a better question than computer help.

Read the answer as a lead

An AI answer, such as an AI Overview, is a quick summary written from many pages. It can sound sure and still be wrong, out of date or about a different town. Treat it as a lead, not a source.

Sync, backup, and recovery

Sync copies changes, including deletions, between your computer and an online service. A backup is a separate copy kept somewhere else. Version history, kept by services such as OneDrive and Google Docs, may bring back earlier wording.

Read-only is not encryption

Read-only stops changes, but the file can still be read and copied. Encryption scrambles the content so only someone with the password or key can read it. A password to open and a password to modify protect different things.
