Lab quick card: Windows 11

Zoom in with Magnifier
Press Windows logo key and + to zoom in. Press Windows logo key and Esc to close Magnifier.
Quiet your notifications
Start › Settings › System › Notifications. Turn off apps you do not need. For a quiet hour, open the notification center and select the bell with zZ to turn on Do not disturb.
See where a link really goes
Point to the link without clicking and read the web address that appears. If it does not match the organization’s real website, do not open it.
Report a phishing email
Outlook.com: select the message, then Report › Report phishing. Gmail: open the message, select More (⋮) next to Reply, then Report phishing.
Turn on two-step verification (at home)
Microsoft account: go to account.microsoft.com/security, select Manage how I sign in, then under Additional security, Two-step verification, select Turn on.
Check for Windows updates
Start › Settings › Windows Update › Check for updates. If updates are listed, select Download & install. Windows 10: Start › Settings › Update & Security › Windows Update.
Review which websites can use your camera
In Edge, open Settings from the ··· menu and type permissions in the Search settings box. Open Camera to see which sites are allowed; select a site to change it to Block.
Lock the computer when you step away
Press Windows logo key and L. Sign in again when you come back.
Require a password to open a Word file
File › Info › Protect Document › Encrypt with Password. Type the password twice, then save. Word cannot recover a lost password.
Stop changes but not reading
File › Info › Protect Document › Always Open Read-Only, or Review › Restrict Editing. Anyone can still read and copy the text.
Check device encryption
Start › Settings › Privacy & security › Device encryption. If it is missing, the computer may not support it or you may be signed in as a standard user.
Bring back something you just deleted
Press Ctrl and Z right away. It works after you save, until you close the file. For a file saved in OneDrive, select the file name at the top, then Version history.
Total a column in Excel
Select the empty cell under the numbers, type =SUM(B2:B5) and press Enter. Select the cell again to see the formula in the formula bar.
