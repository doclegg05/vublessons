Week 5 · Lesson plan

Objectives

  • Set up your computer so it is comfortable and easy to use.
  • Spot a scam or a fake identity and check it a safer way.
  • Protect your devices and files with updates, permissions, locking and passwords.
  • Show five skills from this course, then take the post-test.

Observable outcomes

  • Comfort and access: at a lab workstation, each learner makes one comfort change (chair, screen distance, text size or Magnifier) and says what it made easier, then names two universal design features and who each one helps. The change is visible, and lab settings are restored afterwards.
  • Scams: given the fictional message on slide 8, each learner names two warning signs and an independent check that does not use the message’s link or number, says what to do after typing a password, and gives a safe next step for a catfishing request, fear of missing out and a hurtful post, with no more than one prompt.
  • Devices and files: using slide 9, Edge settings, Windows Update and Word’s Protect Document menu without changing anything, each learner chooses safe responses to an unknown USB drive and an unneeded camera request, says why updates matter, tells a password to open (encryption) apart from read-only, and says what device encryption protects and when to lock the screen. Both knowledge checks are answered correctly.
  • Skills challenge and post-test: working alone, each learner completes the five challenge rows (refined search, structured paragraph, formula total, undo recovery, useful feedback), each rated Independent, With prompt or Needs practice, then completes the 20-question post-test and records the score and one next practice task.

Before class: print worksheet and answer guide; open the lesson and practice library; check projector, keyboard, sound and printer; provide fresh fictional files. The course video is available for optional chapter replay. No learner account or purchase is required.

Teaching rhythm

Tell: explain the purpose using prior experience. Show: ask for a prediction and demonstrate one step at a time. Do: learners act at their own seats using the quick card. Review: explain choices and inspect evidence. Use N for slide-specific instructor notes and the answer guide for expected results.

Pacing and recovery

Protect the 8-minute break. Finish each essential Point B before optional extensions. Offer prepared examples, partner observation and paper annotation when tools are unavailable; record these as simulated work. Use the closing block for consolidation, not a new task.

Mission 5D is a 26-minute observed skills challenge. The following 22 minutes belong to the individual 20-question post-test. Keep observation ratings and test scores separate. Use a paper test if the browser cannot load; keep the complete result as the backup.

Lab quick card: Windows 11

Zoom in with Magnifier
Press Windows logo key and + to zoom in. Press Windows logo key and Esc to close Magnifier.
Quiet your notifications
Start › Settings › System › Notifications. Turn off apps you do not need. For a quiet hour, open the notification center and select the bell with zZ to turn on Do not disturb.
See where a link really goes
Point to the link without clicking and read the web address that appears. If it does not match the organization’s real website, do not open it.
Report a phishing email
Outlook.com: select the message, then Report › Report phishing. Gmail: open the message, select More (⋮) next to Reply, then Report phishing.
Turn on two-step verification (at home)
Microsoft account: go to account.microsoft.com/security, select Manage how I sign in, then under Additional security, Two-step verification, select Turn on.
Check for Windows updates
Start › Settings › Windows Update › Check for updates. If updates are listed, select Download & install. Windows 10: Start › Settings › Update & Security › Windows Update.
Review which websites can use your camera
In Edge, open Settings from the ··· menu and type permissions in the Search settings box. Open Camera to see which sites are allowed; select a site to change it to Block.
Lock the computer when you step away
Press Windows logo key and L. Sign in again when you come back.
Require a password to open a Word file
File › Info › Protect Document › Encrypt with Password. Type the password twice, then save. Word cannot recover a lost password.
Stop changes but not reading
File › Info › Protect Document › Always Open Read-Only, or Review › Restrict Editing. Anyone can still read and copy the text.
Check device encryption
Start › Settings › Privacy & security › Device encryption. If it is missing, the computer may not support it or you may be signed in as a standard user.
Bring back something you just deleted
Press Ctrl and Z right away. It works after you save, until you close the file. For a file saved in OneDrive, select the file name at the top, then Version history.
Total a column in Excel
Select the empty cell under the numbers, type =SUM(B2:B5) and press Enter. Select the cell again to see the formula in the formula bar.

Week-specific preparation

Each station: Microsoft Edge, Word and Excel, and this lesson and worksheet; check that a downloaded .csv file opens in Excel. At the front: the projector with Edge, Word and Windows Settings, and a USB drive to hold up for slide 12 (never plug it in). Print a paper roster with each learner code, five challenge columns, the week 1 pre-test score and a post-test column, and bring the week 1 scores. The lab needs no accounts: the phishing message, camera prompt and file protections are course simulations or look-only steps, and two-step verification is a home task. Ask IT before class whether the lab’s Windows 10 computers get Extended Security Updates, because learners will ask. Check that Windows Update, Edge site permissions and Word’s Protect Document menu open under a learner login. Play chapters 4 and 7 with captions to check sound. After your own run-through, delete any help-desk.docx and supplies files you created and select Start fresh on this computer at each station. Keep 3–5 printed post-tests in case the network fails. No paid service, real purchase or new learner account is required.
