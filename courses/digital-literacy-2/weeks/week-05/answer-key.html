Instructor guide. Accept equivalent evidence-based answers. These activities evaluate demonstrated skills, not speed.

1. Adjust one workstation feature and explain the need it addresses.

An appropriate comfort adjustment and observable benefit; avoid diagnostic claims.

2. Define universal design and name two useful examples.

Usability for diverse people/situations; captions and keyboard controls are examples.

3. For an urgent suspicious message, write an independent verification plan.

Do not use supplied link; find official contact independently.

4. Explain catfishing, FOMO and a constructive response to harmful posts.

False identity; fear of missing out; document/report/block/seek support as appropriate.

5. Choose responses to unknown USB media and an unnecessary camera request.

Do not connect unknown media; deny permissions without a task-related need.

6. Explain device encryption, a file password and editing restrictions without treating them as identical.

Encryption needs a key; passwords can protect opening or editing; read-only does not prove encryption.

7. Performance challenge: refine a public-service search; justify a source; create a structured paragraph; calculate a three-item total; choose sharing access; give useful feedback; name a recovery method.

Mark each of seven tasks Independent / With prompt / Needs practice; keep performance separate from quiz score.

8. Save or print your post-test results. Identify one strength and one next practice task.

Result preserved by learner; specific task linked to a domain that needs practice.
