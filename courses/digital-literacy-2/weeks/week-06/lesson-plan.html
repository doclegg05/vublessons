Week 6 · Lesson plan

Objectives

  • Write checks first, then test a web page with them and write down what you really saw. (Microsoft Edge; practice only, not on the post-test)
  • Write a request for an AI agent that says what to change and what must stay the same. (Microsoft Edge; practice only, not on the post-test)
  • Find a change nobody asked for, and report it as a bug with steps, what you typed, what you expected and what happened. (Microsoft Edge; practice only, not on the post-test)
  • Retest a repair: run the new check and the checks that passed before. (Microsoft Edge; practice only, not on the post-test)

Observable outcomes

  • Checks: in Edge, each learner opens version 1, searches library, learning, zzz and LIBRARY, and writes what they saw on the test table (1 found, none found, none found, 1 found).
  • Request: each learner types the four-line request on the worksheet and writes a guess for each of the four searches in the new version.
  • Bug report: each learner opens version 2, sees learning find 2 and LIBRARY find none, and writes a bug report with the steps, what they typed, what they expected and what happened.
  • Retest: each learner opens version 3, reruns all four searches (1, 2, none, 1), tabs through the controls, zooms in, and fills in the My result page.

How this lesson runs

You project the deck and the class does each step together, one or two clicks per slide. Every step slide names the program in its top corner, gives the clicks, and says what learners should see. The worksheet repeats every step with a check box, so anyone who falls behind can catch up, and adds an If you get stuck box for each part. Wait for every screen to match before moving on.

Each part opens with a slide naming the program, then why it matters, a short video clip, the steps and one check question. Everything happens together in Microsoft Edge. The AI agent’s work is pre-built as three versions of one practice page, so nobody needs an AI account. After the wrap-up, the class reviews weeks 1 to 5 (a recap slide and the check questions for each week, 20 in all, one for each post-test skill), then opens the post-test together. The post-test is the only time learners work alone. The video chapters on websites and web apps, how a page is built, where data lives, secret keys, and repairing a file by hand are not played. There is no break and no timer. Minutes below are a guide for pacing, not a clock for learners.

Week-specific preparation

Each station: Microsoft Edge and the Week 6 worksheet. The three practice pages (resource-finder.html, resource-finder-agent.html and resource-finder-agent-fixed.html) work in Edge on every computer and need no account. Before class, open each from the worksheet and check that LIBRARY finds one entry in versions 1 and 3 and none in version 2. Check sound on the projector: play the first Watch slide. For the post-test, check that the course home opens and that the post-test page opens, and have Britt’s flash drives ready. Keep a roster for the end-of-class check. After your own run-through, select Start fresh on this computer at each station.
