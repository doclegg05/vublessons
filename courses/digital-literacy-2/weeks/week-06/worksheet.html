Turn a clear need into a tested, accessible prototype using basic vibe coding.

Name or learner code: ____________________

Use fictional information. Work with a partner, take turns, and record what you actually observed. Type below or print a blank copy. Typed worksheet responses stay on this page only; print before closing.

1. Name the app’s user, problem and three acceptance checks. Keep the scope to one page.

2. Write a prompt naming content, behavior, accessibility and privacy boundaries.

3. Open the starter. Save a copy as resource-finder-v1.html using a plain-text editor. If working offline, no AI tool is required.

4. Find the <h1> heading in the source and replace only its text. In the resources array, change the fictional Community library name to Community Skills Desk. Save as resource-finder-v2.html, reopen it, and search skills to confirm Community Skills Desk appears.

5. Ask an approved AI tool for one small improvement, or make the heading/data edit manually. Record exactly what changed.

6. Test blank input, matching and nonmatching search, mixed case, category filters, keyboard focus and narrow-screen layout. Record expected, actual and pass/fail.

7. Fix one defect or improve one requirement. Repeat its test and one previously passing test. Keep both versions.

8. Demonstrate the app. Explain HTML/CSS/JavaScript, where data lives, and why a public SaaS service needs additional design and maintenance.

Save and open your own copy (no AI account needed)

  1. Select Download editable HTML above. The file resource-finder-v1.html goes to your Downloads folder.
  2. Open it in a plain-text editor. On Windows, right-click the file, choose Open with, then Notepad. On a Mac, open TextEdit, choose Format, then Make Plain Text, then open the file.
  3. Make your edit. Choose File, then Save As. Type resource-finder-v2.html as the name. On Windows, set Save as type to All files so Notepad does not add .txt. On a Mac, untick the box that adds .txt when no extension is given.
  4. Double-click the saved file to open it in your browser. Search skills. Confirm that Community Skills Desk appears and that the heading changed.

Turn AI output into a file you can run

  1. Paste your prompt into the approved AI tool. Ask for one complete HTML file, not separate pieces.
  2. Select the code block the tool gives you and copy it with Ctrl and C (Command and C on a Mac).
  3. Open a new plain-text document, paste with Ctrl and V (Command and V), and save it as resource-finder-ai.html using the same Save As steps above.
  4. Open the saved file in your browser. Run the three acceptance checks yourself before trusting anything the AI said about it.
