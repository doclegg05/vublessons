  4. To compare two versions, open each in its own window (Ctrl and N). Press the Windows logo key and the Left arrow on one window, then pick the other for the right side.

Check the change yourself (no AI account needed)

  1. On version 2, press Ctrl and U. The page’s code opens in a new tab. You can read it but not change it.
  2. Press Ctrl and F and type toLowerCase. Count how many places are highlighted. Do the same on version 1.
  3. If the counts differ, find that line in the diff on slide 10. Ask: did our spec ask for this change?

Optional: repair version 2 by hand

  1. Under the agent’s version, select Download editable HTML. The file resource-finder-v2.html goes to your Downloads folder (Ctrl and J shows it).
  2. In File Explorer, right-click the file, select Open with, then Notepad. On a Mac, first choose TextEdit › Settings › Open and Save and turn on Display HTML files as HTML code instead of formatted text, then open the file in TextEdit.
  3. Press Ctrl and F (Command and F on a Mac) and type trim(). On that line, type .toLowerCase() right after trim() so it reads trim().toLowerCase();
  4. Choose File, then Save As. Type resource-finder-v3.html. On Windows, set Save as type to All files so Notepad does not add .txt. On a Mac, choose Use .html if TextEdit asks.
  5. Double-click the saved file to open it in your browser. Retest LIBRARY, Learning and zzz, then one check that passed before.

1. Write a change request (a spec) for the agent in plain English. The need: visitors type a kind of help, like learning, not a name. Say the one change, who it helps, and two things that must stay the same. The slide 7 builder can make a first draft.

2. Write three acceptance checks in the form I type or press this, I expect to see that. Make one check about the new change and one about something that already works and must not break.

3. Before the agent runs, predict: which part will it change (HTML, CSS or JavaScript), about how many lines, and one thing that could break. Then read the agent's plan on the projector and write one way it matches or differs from your prediction.

4. Open slide 10 and read the agent's change (the diff). A line with a minus sign was removed; a line with a plus sign was added. Mark each changed line asked for or not asked for, and write down the change that breaks what the spec said to keep.

5. Open the agent's version (resource-finder-agent.html) at your own seat. Run the five checks in the App test log: happy path (learning, then library), no match (zzz), mixed case (LIBRARY, then Learning), keyboard only, and narrow screen (zoom to 400%). Record expected, actual and pass or fail.

6. Write a repair request the agent could act on: the steps, what you expected, what actually happened, and what must stay the same.

7. Open the repaired version (resource-finder-agent-fixed.html). Repeat the check that failed, then two checks that passed before. Record the results and say whether you accept the repair.

8. Suppose the finder became a SaaS website where many people save favorite resources. Write where it would be hosted, why visitors would sign in, where saved favorites would live, where a private API key for a map service would go, and what it would cost and who would keep it running.

Lab quick card: Windows 11

Click-by-click steps for this week’s tasks in Windows 11 with Microsoft Edge. If your screen looks different, ask your instructor.

To do thisSteps
Put two pages side by sidePress Ctrl and N to open a second Edge window and open the other version there. Press the Windows logo key and the Left arrow, then choose the other window for the right side. Or hover over the Maximize button and pick a layout.
See a page's codePress Ctrl and U. The code opens in a new tab; you can read it but not change it. Close that tab when you are done.
Find a word on a page or in its codePress Ctrl and F and type the word. Matches are highlighted. Press Ctrl and G to jump to the next one.
Reload a pagePress F5, or Ctrl and R.
Test with the keyboard onlyPress Tab to move to the next control and Shift and Tab to go back. Each control should show a thick outline. On Category, press the Up or Down arrow to change the choice. On Reset filters, press Enter.
Test a narrow screenPress Ctrl and + until the zoom reaches 400%. The page should become one column you can read without scrolling sideways. Press Ctrl and 0 to go back to 100%.
Show file name extensionsIn File Explorer, select View › Show › File name extensions. Names now end in .html or .txt, so you can spot a wrong save.
Find a downloaded filePress Ctrl and J to open Downloads in Edge. Downloaded files are in the Downloads folder in File Explorer.
Open an HTML file in NotepadIn File Explorer, right-click the file, select Open with, then Notepad. If Notepad is not listed, select Choose another app.
Save a web page from NotepadChoose File › Save as. Type a name ending in .html. Set Save as type to All files, then select Save. Or type the whole name in quotation marks, such as "resource-finder-v3.html".
