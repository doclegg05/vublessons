Before you begin

Open the three versions (no account needed)

  1. Version 1, before the agent: go to practice library exercise 9 and select Open starter app, or select Open version 1 above.
  2. Version 2, the agent’s result: select Open the agent’s version above. This is resource-finder-agent.html.
  3. Version 3, after the repair: select Open the repaired version above only when your instructor says so. This is resource-finder-agent-fixed.html.
  4. To compare two versions, open each in its own window (Ctrl and N). Press the Windows logo key and the Left arrow on one window, then pick the other for the right side.

Check the change yourself (no AI account needed)

  1. On version 2, press Ctrl and U. The page’s code opens in a new tab. You can read it but not change it.
  2. Press Ctrl and F and type toLowerCase. Count how many places are highlighted. Do the same on version 1.
  3. If the counts differ, find that line in the diff on practice library exercise 10. Ask: did our spec ask for this change?

Optional: repair version 2 by hand

  1. Under the agent’s version, select Download editable HTML. The file resource-finder-v2.html goes to your Downloads folder (Ctrl and J shows it).
  2. In File Explorer, right-click the file, select Open with, then Notepad. On a Mac, first choose TextEdit › Settings › Open and Save and turn on Display HTML files as HTML code instead of formatted text, then open the file in TextEdit.
  3. Press Ctrl and F (Command and F on a Mac) and type trim(). On that line, type .toLowerCase() right after trim() so it reads trim().toLowerCase();
  4. Choose File, then Save As. Type resource-finder-v3.html. On Windows, set Save as type to All files so Notepad does not add .txt. On a Mac, choose Use .html if TextEdit asks.
  5. Double-click the saved file to open it in your browser. Retest LIBRARY, Learning and zzz, then one check that passed before.

Mission 6A · Specify the change

Point A

Version 1 searches names and descriptions

Point B

A precise category-search request

App: AI-agent specification · Interactive practice

  1. Write a change request (a spec) for the agent in plain English. The need: visitors type a kind of help, like learning, not a name. Say the one change, who it helps, and two things that must stay the same. The practice library exercise 7 builder can make a first draft.
  2. Write three acceptance checks in the form I type or press this, I expect to see that. Make one check about the new change and one about something that already works and must not break.

Route used: app / simulation / paper · Support: independent / with prompt / needs practice

Mission 6B · Review the proposed change

Point A

The agent returns version 2

Point B

Asked-for changes separated from regressions

App: Change review · Interactive practice

  1. Before the agent runs, predict: which part will it change (HTML, CSS or JavaScript), about how many lines, and one thing that could break. Then read the agent's plan on the projector and write one way it matches or differs from your prediction.
  2. Open practice library exercise 10 and read the agent's change (the diff). A line with a minus sign was removed; a line with a plus sign was added. Mark each changed line asked for or not asked for, and write down the change that breaks what the spec said to keep.

Route used: app / simulation / paper · Support: independent / with prompt / needs practice

Mission 6C · Test, report, repair, retest

Point A

A plausible app with a planted defect

Point B

A repair supported by repeatable evidence

App: Three-version test lab · Interactive practice

  1. Open the agent's version (resource-finder-agent.html) at your own seat. Run the five checks in the App test log: happy path (learning, then library), no match (zzz), mixed case (LIBRARY, then Learning), keyboard only, and narrow screen (zoom to 400%). Record expected, actual and pass or fail.
  2. Write a repair request the agent could act on: the steps, what you expected, what actually happened, and what must stay the same.
  3. Open the repaired version (resource-finder-agent-fixed.html). Repeat the check that failed, then two checks that passed before. Record the results and say whether you accept the repair.

Route used: app / simulation / paper · Support: independent / with prompt / needs practice

Mission 6D · Know what “ready” means

Point A

A local prototype on your computer

Point B

A clear boundary and an operating owner

App: Web app / SaaS · Interactive practice

  1. Suppose the finder became a SaaS website where many people save favorite resources. Write where it would be hosted, why visitors would sign in, where saved favorites would live, where a private API key for a map service would go, and what it would cost and who would keep it running.

Lab quick card: Windows 11

Put two pages side by side
Press Ctrl and N to open a second Edge window and open the other version there. Press the Windows logo key and the Left arrow, then choose the other window for the right side. Or hover over the Maximize button and pick a layout.
See a page's code
Press Ctrl and U. The code opens in a new tab; you can read it but not change it. Close that tab when you are done.
Find a word on a page or in its code
Press Ctrl and F and type the word. Matches are highlighted. Press Ctrl and G to jump to the next one.
Reload a page
Press F5, or Ctrl and R.
Test with the keyboard only
Press Tab to move to the next control and Shift and Tab to go back. Each control should show a thick outline. On Category, press the Up or Down arrow to change the choice. On Reset filters, press Enter.
Test a narrow screen
Press Ctrl and + until the zoom reaches 400%. The page should become one column you can read without scrolling sideways. Press Ctrl and 0 to go back to 100%.
Show file name extensions
In File Explorer, select View › Show › File name extensions. Names now end in .html or .txt, so you can spot a wrong save.
Find a downloaded file
Press Ctrl and J to open Downloads in Edge. Downloaded files are in the Downloads folder in File Explorer.
Open an HTML file in Notepad
In File Explorer, right-click the file, select Open with, then Notepad. If Notepad is not listed, select Choose another app.
Save a web page from Notepad
Choose File › Save as. Type a name ending in .html. Set Save as type to All files, then select Save. Or type the whole name in quotation marks, such as "resource-finder-v3.html".
