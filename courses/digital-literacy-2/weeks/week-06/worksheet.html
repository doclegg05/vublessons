Words we use tonight

Tab
One of the page names along the top of Edge. Click a tab to switch pages.
Address bar
The long box at the top of Edge where you type a website name.
Check
A test you can run: type this, and you expect to see that.
AI agent
A program that changes a file for you when you ask it to.
Request
The words you give an AI agent. It says what to change and what must stay the same.
Version
One saved copy of the page. Version 2 is the agent’s change. Version 3 is the repair.
Bug
Something that does not work the way it should.
Bug report
A short note that lets someone else see the bug: the steps, what you typed, what you expected, what happened.
Retest
Run the checks again after a change, the old ones as well as the new one.
Focus ring
The thick outline that shows which control the keyboard is on.
