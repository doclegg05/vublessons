Website, web app, and SaaS

A website shows pages. A web app responds when you type or click. SaaS (software as a service) is software you use in a browser while a company hosts it, keeps the data, secures it and updates it, usually for a fee.

Keep secrets out of browser code

An API key is a secret code that lets your app use another company's service, such as maps, and bills you for it. Anyone can read a page's code (Ctrl and U), so private keys stay on the server.

A mock sign-in is not security

Authentication means proving who you are, usually by signing in. A sign-in box drawn on a page protects nothing. A real SaaS checks who you are on its server, then decides what each person may see.

Hosting is a separate decision

Hosting means putting the page on a web server so anyone with the address can use it. Running it as a service also means costs, backups, updates, support and a person who reviews every agent change.
