Website, web app, and SaaS

A website presents pages. A web app adds interactive tasks. SaaS is software operated as an ongoing online service; it may need accounts, shared storage, support and maintenance.

Vibe coding starts with clear instructions

Describe the result you want in ordinary language, ask AI to produce code, then inspect and test what it gives you. You are responsible for the result.

Make one change at a time

Save version 1. Ask for a small change. Review the difference. Test again. Restore version 1 if the change breaks a requirement.

A useful revision request

The filter works with a mouse but the focus is hard to see. Add a clear focus outline to all controls. Keep existing search behavior and fictional data.

Where does the data live?

A JavaScript array is bundled with the page. Browser storage belongs to that browser and can be cleared. A shared database supports cross-device data and requires access controls.

Keep secrets out of browser code

Anything shipped to a browser can be inspected. Do not put API keys, passwords or private records in HTML or JavaScript. Use fictional records for this prototype.

A mock sign-in is not security

A login-looking screen does not protect data by itself. Real accounts need server-side authorization, safe credential handling and tested access rules.

Hosting is a separate decision

A local file is visible on your computer. Hosting makes it reachable online. Before a real launch, review content rights, access, data handling, costs, backups and who maintains it.
