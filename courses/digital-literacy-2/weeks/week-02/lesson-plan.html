Week 2 lesson plan: Find, judge, and organize information

Course home

Find a reliable community resource and manage a shared file with care.

Learning outcomes

  • Search: in Microsoft Edge at a lab workstation, given a local service need, each learner writes a search that names the service, the provider and the place, then applies one refinement (quotation marks, site: or a date range) and says in one sentence what it changed. Correct with no more than one prompt, and no plus signs.
  • Sources: for one result from that search, each learner records the five source fields (title, organization, web address, date checked and the detail used), answers the five source questions from slide 5, and names one detail to confirm with the organization that runs the service. All five fields are present and each judgment points to something on the page.
  • Forms: using the practice form on slide 10 with fictional details, each learner submits once with a required choice missing, reads the message, completes the form, and explains that the confirmation does not mean anyone received a request.
  • Files: in File Explorer at a lab workstation, each learner makes a folder named Community resources, saves a Word file in it as library-help-v1.docx, reopens it from that folder, compresses the folder to a ZIP file, extracts it and opens the extracted copy. All steps done, with nothing saved in the wrong place.
  • Access and recovery: using the permission practice on slide 15 (simulated), each learner chooses Viewer, Commenter or Editor for a reader, a reviewer and a co-writer, giving each the least access the task needs; restores a deleted practice file from the Recycle Bin; says when version history is the right tool instead; and says that read-only stops changes but is not encryption. All correct with no more than one prompt.

Prepare the room

Each station: Microsoft Edge, Microsoft Word (Notepad works if Word is missing; save as library-help-v1.txt), File Explorer with a local Documents folder that is not signed in to OneDrive, headphones, and this lesson and worksheet. At the front: the projector showing Edge, File Explorer and Word, and one real West Virginia public library page for the search and source demonstrations, checked the day before. The lab has no cloud account for learners, so sharing (worksheet task 7) and version history (task 8) use the slide 15 and slide 18 practice, marked simulated; if you have your own OneDrive or Google account, you may show the Share box and version history on the projector with a fictional file only. No printing is needed; decide whether learners may print their worksheet or should save it as a PDF before closing. Play video chapters 2, 6 and 7 with captions to check sound, and mark the pause points 1:17, 3:29, 5:02 and 6:35. After your own run-through, delete your practice folder and ZIP from Documents and select Start fresh on this computer at each station. No paid service, real purchase or new learner account is required.

For unavailable features, use the course simulation or role play and label the evidence as simulated.

Lab quick card: Windows 11

Click-by-click steps for this week’s tasks in Windows 11 with Microsoft Edge. If your screen looks different, ask your instructor.

To do thisSteps
Search from the address barPress Ctrl and L, type your words and press Enter. Edge searches with Bing. Plus signs are not needed between words.
Search for an exact phrasePut the phrase in quotation marks, for example "computer help". Remove the quotation marks if you get too few results.
Search one kind of websiteType site: and the site or ending with no space, then your words, for example site:gov library computer help.
Show only recent resultsGo to google.com and search. Below the search box, select Tools, then Any time, and choose a range such as Past year.
Find a word on a long pagePress Ctrl and F, then type the word you want to find on the page.
Copy a web address into your notesPress Ctrl and L to select the address, then Ctrl and C to copy it. Click in your notes and press Ctrl and V to paste.
Make a new folderPress the Windows logo key and E to open File Explorer. Open Documents, select New › Folder, type the name and press Enter. Or press Ctrl and Shift and N.
Save a Word file into that folderIn Word, select File › Save As › Browse. Open Documents › Community resources, type the File name, then select Save.
Rename a fileIn File Explorer, select the file and press F2, or right-click it and select Rename. Type the new name and press Enter.
Make a ZIP fileRight-click the folder, then select Show more options › Send to › Compressed (zipped) folder. The ZIP file appears next to the folder.
Open the files in a ZIPRight-click the ZIP file, select Extract All, then follow the steps. Open the files from the new folder, not from inside the ZIP.
Get back a deleted fileOpen the Recycle Bin on the desktop, right-click the file and select Restore. It returns to its folder. Shift and Delete skips the Recycle Bin.
Protect a Word file (instructor shows)File › Info › Protect Document. Always Open Read-Only limits changes; Encrypt with Password asks for a password to open. Word cannot recover a lost password.
Share or see earlier versions (instructor shows; needs an account)OneDrive: select the file › Share, then choose Can view or Can edit; right-click the file › Version history. Google Drive: Share › Viewer, Commenter or Editor; in a Google Doc, select Last edit at the top right to see versions.

Using the chaptered video

Play each chapter inside its cycle, as the Show, from the video slide. Pause at the times named in the plan; the narration does not stop by itself. Ask learners to predict before a demonstration and explain the evidence afterward. Replay only the chapter needed for a refresher.

Facilitation and access

Demonstrate slowly, then let learners try. Offer keyboard and mouse paths, captions and the written transcript. Print large copies if needed. Every learner works at their own workstation; a partner coaches but does not take over. Provide extra practice time without requiring learners to disclose a disability.

Evidence to collect

  • Write a question about a local public service you or a neighbor might need, such as computer help at a public library. Name the service and the town.
  • In Edge, search for that service and record your search. Then refine it one way: a phrase in quotation marks, site:gov, or Tools › Any time on google.com. Record what changed. Plus signs are not needed.
  • Open one result that answers your question. Record the page title, the organization, the web address (Ctrl and L, Ctrl and C, then Ctrl and V here), today's date and the one detail you will use.
  • For that page, answer the five source questions from slide 5 in a few words each: who made it, what evidence it gives, why it was published, whether it is current, and whether it fits your question. Name one detail to confirm with the organization.
  • On slide 10, select Review practice request with one choice left blank, and write the message you see. Then choose a topic and a contact method, submit, and copy the confirmation. Say what the confirmation does not prove.
  • Open File Explorer (Windows logo key and E) › Documents. Make a folder named Community resources. In Word, type your task 1 question and task 3 source note, and save the file in that folder as library-help-v1.docx. Close Word, reopen the file from the folder, and say who controls a copy kept in a cloud drive.
  • On slide 15, choose access for three people: one who only reads, one who suggests wording, and one who writes the handout with you. Record each role and why, and mark it simulated. Say what read-only does and does not do.
  • Right-click Community resources › Show more options › Send to › Compressed (zipped) folder. Right-click the ZIP file › Extract All, then open the extracted file. Delete that file and restore it from the Recycle Bin. On slide 18, choose the route for wrong wording and mark it simulated.

Feedback and differentiation

Ask the learner to explain a choice and demonstrate the result. Mark Independent, With prompt, or Needs practice. Re-model only the missing step. For faster learners, ask them to test an edge case or explain an alternative; do not add unrelated tasks.
