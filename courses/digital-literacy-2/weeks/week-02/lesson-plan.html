Week 2 · Lesson plan

Objectives

  • Ask a search tool a full-sentence question that names the service, the place and one detail, then refine it with a follow-up.
  • Read an AI answer as a lead, check it against the organization's own page, and record where you found it.
  • Fill in an online form with only what is needed, and read the confirmation.
  • Save a file with a clear name in a folder you can find, and pack it in a ZIP file.
  • Choose who can view, comment or edit, and pick the right way to get a file back.

Observable outcomes

  • Search: in Microsoft Edge at a lab workstation, given a local service need, each learner asks Google a full-sentence question that names the service, the place and one detail, asks one follow-up, and says in one sentence what the follow-up changed. No private details typed. Correct with no more than one prompt.
  • Sources: for one source link from that answer, each learner records the five source fields (title, organization, web address, date checked and the detail used), answers the three source checks (who published it, when it was updated, whether it fits), and names one detail in the AI answer that the page does not confirm. All five fields are present and each judgment points to something on the page.
  • Forms: using the practice form on the Mission 2B practice page with fictional details, each learner submits once with a required choice missing, reads the message, completes the form, and explains that the confirmation does not mean anyone received a request.
  • Files: in File Explorer at a lab workstation, each learner makes a folder named Community resources, saves a Word file in it as library-help-v1.docx, reopens it from that folder, compresses the folder to a ZIP file, extracts it and opens the extracted copy. All steps done, with nothing saved in the wrong place.
  • Access and recovery: using the permission practice on the Mission 2D practice page (simulated), each learner chooses Viewer, Commenter or Editor for a reader, a reviewer and a co-writer, giving each the least access the task needs; restores a deleted practice file from the Recycle Bin; says when version history is the right tool instead; and says that read-only stops changes but is not encryption. All correct with no more than one prompt.

Lab quick card: Windows 11

Ask a full-sentence question
Press Ctrl and L, type your question as you would ask a person (the service, the place and one detail) and press Enter. Google may show an AI Overview above the results. If an AI Mode button or tab appears, select it to keep asking follow-up questions.
Ask a follow-up
Type a short follow-up in the same place, such as: Which of these are open on Saturdays? You do not need to start over.
Open the source behind an answer
Look for links beside or beneath the answer and open the organization's own page. Check who published it and when it was updated.
Keep private details out of a question
Do not type a Social Security number, bank or card number, password, claim number or health details into a question.
Find a word on a long page
Press Ctrl and F, then type the word you want to find on the page.
Copy a web address into your notes
Press Ctrl and L to select the address, then Ctrl and C to copy it. Click in your notes and press Ctrl and V to paste.
Make a new folder
Press the Windows logo key and E to open File Explorer. Open Documents, select New › Folder, type the name and press Enter. Or press Ctrl and Shift and N.
Save a Word file into that folder
In Word, select File › Save As › Browse. Open Documents › Community resources, type the File name, then select Save.
Rename a file
In File Explorer, select the file and press F2, or right-click it and select Rename. Type the new name and press Enter.
Make a ZIP file
Right-click the folder, then select Show more options › Send to › Compressed (zipped) folder. The ZIP file appears next to the folder.
Open the files in a ZIP
Right-click the ZIP file, select Extract All, then follow the steps. Open the files from the new folder, not from inside the ZIP.
Get back a deleted file
Open the Recycle Bin on the desktop, right-click the file and select Restore. It returns to its folder. Shift and Delete skips the Recycle Bin.
Protect a Word file (instructor shows)
File › Info › Protect Document. Always Open Read-Only limits changes; Encrypt with Password asks for a password to open. Word cannot recover a lost password.
Share or see earlier versions (instructor shows; needs an account)
OneDrive: select the file › Share, then choose Can view or Can edit; right-click the file › Version history. Google Drive: Share › Viewer, Commenter or Editor; in a Google Doc, select Last edit at the top right to see versions.

Week-specific preparation

Each station: Microsoft Edge, Microsoft Word (Notepad works if Word is missing; save as library-help-v1.txt), File Explorer with a local Documents folder that is not signed in to OneDrive, headphones, and this lesson and worksheet. At the front: the projector showing Edge, File Explorer and Word, and one real West Virginia public library page for the source demonstration, checked the day before. The lab has no cloud account for learners, so sharing (worksheet task 7) and version history (task 8) use the Mission 2D and Mission 2C practice pages, marked simulated; if you have your own OneDrive or Google account, you may show the Share box and version history on the projector with a fictional file only. No printing is needed; decide whether learners may print their worksheet or should save it as a PDF before closing. Play video chapters 2, 6 and 7 with captions to check sound, and mark the pause points 1:26, 2:22, 3:41, 5:14 and 6:47. Google shows an AI Overview for some questions only, and AI Mode may not appear for every learner: rehearse your demonstration question the day before, and use the fictional AI answer on the worksheet (Mission A, Round 3) if no AI answer appears. No sign-in is needed. After your own run-through, delete your practice folder and ZIP from Documents and select Start fresh on this computer at each station. No paid service, real purchase or new learner account is required.
