Week 2 · Lesson plan

Objectives

  • Write a clear search and narrow it with one filter.
  • Judge whether a source fits your question, and record where you found it.
  • Fill in an online form with only what is needed, and read the confirmation.
  • Save a file with a clear name in a folder you can find, and pack it in a ZIP file.
  • Choose who can view, comment or edit, and pick the right way to get a file back.

Observable outcomes

  • Search: in Microsoft Edge at a lab workstation, given a local service need, each learner writes a search that names the service, the provider and the place, then applies one refinement (quotation marks, site: or a date range) and says in one sentence what it changed. Correct with no more than one prompt, and no plus signs.
  • Sources: for one result from that search, each learner records the five source fields (title, organization, web address, date checked and the detail used), answers the five source questions from slide 5, and names one detail to confirm with the organization that runs the service. All five fields are present and each judgment points to something on the page.
  • Forms: using the practice form on slide 10 with fictional details, each learner submits once with a required choice missing, reads the message, completes the form, and explains that the confirmation does not mean anyone received a request.
  • Files: in File Explorer at a lab workstation, each learner makes a folder named Community resources, saves a Word file in it as library-help-v1.docx, reopens it from that folder, compresses the folder to a ZIP file, extracts it and opens the extracted copy. All steps done, with nothing saved in the wrong place.
  • Access and recovery: using the permission practice on slide 15 (simulated), each learner chooses Viewer, Commenter or Editor for a reader, a reviewer and a co-writer, giving each the least access the task needs; restores a deleted practice file from the Recycle Bin; says when version history is the right tool instead; and says that read-only stops changes but is not encryption. All correct with no more than one prompt.

Teaching rhythm

Tell: explain the purpose using prior experience. Show: ask for a prediction and demonstrate one step at a time. Do: learners act at their own seats using the quick card. Review: explain choices and inspect evidence. Use N for slide-specific instructor notes and the answer guide for expected results.

Pacing and recovery

Protect the 8-minute break. Finish each essential Point B before optional extensions. Offer prepared examples, partner observation and paper annotation when tools are unavailable; record these as simulated work. Use the closing block for consolidation, not a new task.

Lab quick card: Windows 11

Search from the address bar
Press Ctrl and L, type your words and press Enter. Edge searches with Bing. Plus signs are not needed between words.
Search for an exact phrase
Put the phrase in quotation marks, for example "computer help". Remove the quotation marks if you get too few results.
Search one kind of website
Type site: and the site or ending with no space, then your words, for example site:gov library computer help.
Show only recent results
Go to google.com and search. Below the search box, select Tools, then Any time, and choose a range such as Past year.
Find a word on a long page
Press Ctrl and F, then type the word you want to find on the page.
Copy a web address into your notes
Press Ctrl and L to select the address, then Ctrl and C to copy it. Click in your notes and press Ctrl and V to paste.
Make a new folder
Press the Windows logo key and E to open File Explorer. Open Documents, select New › Folder, type the name and press Enter. Or press Ctrl and Shift and N.
Save a Word file into that folder
In Word, select File › Save As › Browse. Open Documents › Community resources, type the File name, then select Save.
Rename a file
In File Explorer, select the file and press F2, or right-click it and select Rename. Type the new name and press Enter.
Make a ZIP file
Right-click the folder, then select Show more options › Send to › Compressed (zipped) folder. The ZIP file appears next to the folder.
Open the files in a ZIP
Right-click the ZIP file, select Extract All, then follow the steps. Open the files from the new folder, not from inside the ZIP.
Get back a deleted file
Open the Recycle Bin on the desktop, right-click the file and select Restore. It returns to its folder. Shift and Delete skips the Recycle Bin.
Protect a Word file (instructor shows)
File › Info › Protect Document. Always Open Read-Only limits changes; Encrypt with Password asks for a password to open. Word cannot recover a lost password.
Share or see earlier versions (instructor shows; needs an account)
OneDrive: select the file › Share, then choose Can view or Can edit; right-click the file › Version history. Google Drive: Share › Viewer, Commenter or Editor; in a Google Doc, select Last edit at the top right to see versions.

Week-specific preparation

Each station: Microsoft Edge, Microsoft Word (Notepad works if Word is missing; save as library-help-v1.txt), File Explorer with a local Documents folder that is not signed in to OneDrive, headphones, and this lesson and worksheet. At the front: the projector showing Edge, File Explorer and Word, and one real West Virginia public library page for the search and source demonstrations, checked the day before. The lab has no cloud account for learners, so sharing (worksheet task 7) and version history (task 8) use the slide 15 and slide 18 practice, marked simulated; if you have your own OneDrive or Google account, you may show the Share box and version history on the projector with a fictional file only. No printing is needed; decide whether learners may print their worksheet or should save it as a PDF before closing. Play video chapters 2, 6 and 7 with captions to check sound, and mark the pause points 1:17, 3:29, 5:02 and 6:35. After your own run-through, delete your practice folder and ZIP from Documents and select Start fresh on this computer at each station. No paid service, real purchase or new learner account is required.
