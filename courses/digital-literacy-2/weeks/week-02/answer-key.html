Week 2 worksheet answer guide

Course home

Instructor guide. Accept equivalent evidence-based answers. These activities evaluate demonstrated skills, not speed.

1. Write a question about a local public service you or a neighbor might need, such as computer help at a public library. Name the service and the town.

The question names a service and a town, for example: Where can I get computer help at a public library in [town]?

2. In Edge, search for that service and record your search. Then refine it one way: a phrase in quotation marks, site:gov, or Tools › Any time on google.com. Record what changed. Plus signs are not needed.

The first search names the service and place, with no plus signs. One refinement is used (quotation marks, site:gov or a date range) and its effect is stated, such as fewer, more local or more recent results. Ranking is not treated as proof.

3. Open one result that answers your question. Record the page title, the organization, the web address (Ctrl and L, Ctrl and C, then Ctrl and V here), today's date and the one detail you will use.

All five fields: page title, organization, full web address, date checked and one specific detail. No personal records.

4. For that page, answer the five source questions from slide 5 in a few words each: who made it, what evidence it gives, why it was published, whether it is current, and whether it fits your question. Name one detail to confirm with the organization.

Who made it (credibility), what evidence it gives (accuracy), why it was published (perspective and bias), whether it is current, and whether it fits the question (relevance), each tied to something on the page. One detail, such as hours or eligibility, to confirm through the organization's own contact.

5. On slide 10, select Review practice request with one choice left blank, and write the message you see. Then choose a topic and a contact method, submit, and copy the confirmation. Say what the confirmation does not prove.

Message: Please select an item in the list. Confirmation: Practice complete … No request was sent. It shows the exercise was done, not that anyone received a request.

6. Open File Explorer (Windows logo key and E) › Documents. Make a folder named Community resources. In Word, type your task 1 question and task 3 source note, and save the file in that folder as library-help-v1.docx. Close Word, reopen the file from the folder, and say who controls a copy kept in a cloud drive.

Documents › Community resources holds library-help-v1.docx, reopened from that folder. The service and account (or the organization) control a cloud copy; the person who shares a file stays the owner.

7. On slide 15, choose access for three people: one who only reads, one who suggests wording, and one who writes the handout with you. Record each role and why, and mark it simulated. Say what read-only does and does not do.

Reader: Viewer. Reviewer: Commenter, or the nearest option the service offers. Co-writer: Editor. Named people and the least access each task needs, marked simulated. Read-only stops changes but the file can still be read and copied; it is not encryption.

8. Right-click Community resources › Show more options › Send to › Compressed (zipped) folder. Right-click the ZIP file › Extract All, then open the extracted file. Delete that file and restore it from the Recycle Bin. On slide 18, choose the route for wrong wording and mark it simulated.

The ZIP file holds the folder and the extracted file opens. The deleted file is back in its folder from the Recycle Bin. Wrong wording: version history (simulated; it needs a service such as OneDrive or Google Docs). Missing file: the Recycle Bin or the service's recycle bin. Backup: a separate copy for when every synced copy is gone. A ZIP packages files; it is not encryption or a backup.
