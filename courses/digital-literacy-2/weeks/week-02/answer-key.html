Week 2 · Answer and observation guide

Assess observable evidence. A spoken prompt is “With prompt”; using the quick card alone can be independent. Mark simulated work separately from hands-on performance. These observations do not change assessment scores.

Mission 2A · Find a trustworthy answer

  1. The question names a service and a town, for example: Where can I get computer help at a public library in [town]?
  2. The first search names the service and place, with no plus signs. One refinement is used (quotation marks, site:gov or a date range) and its effect is stated, such as fewer, more local or more recent results. Ranking is not treated as proof.
  3. All five fields: page title, organization, full web address, date checked and one specific detail. No personal records.
  4. Who made it (credibility), what evidence it gives (accuracy), why it was published (perspective and bias), whether it is current, and whether it fits the question (relevance), each tied to something on the page. One detail, such as hours or eligibility, to confirm through the organization's own contact.

Review: Confirm through the library’s official contact. Recent and relevant are different from verified.

Mission 2B · Complete a form carefully

  1. Message: Please select an item in the list. Confirmation: Practice complete … No request was sent. It shows the exercise was done, not that anyone received a request.

Review: This is an account-free simulation. It practices validation and reading a confirmation, not delivery.

Mission 2C · Organize and recover a file

  1. Documents › Community resources holds library-help-v1.docx, reopened from that folder. The service and account (or the organization) control a cloud copy; the person who shares a file stays the owner.
  2. The ZIP file holds the folder and the extracted file opens. The deleted file is back in its folder from the Recycle Bin. Wrong wording: version history (simulated; it needs a service such as OneDrive or Google Docs). Missing file: the Recycle Bin or the service's recycle bin. Backup: a separate copy for when every synced copy is gone. A ZIP packages files; it is not encryption or a backup.

Review: Recycle Bin recovers deleted files. Version history can recover earlier content of a cloud file.

Mission 2D · Share only the access needed

  1. Reader: Viewer. Reviewer: Commenter, or the nearest option the service offers. Co-writer: Editor. Named people and the least access each task needs, marked simulated. Read-only stops changes but the file can still be read and copied; it is not encryption.
  2. The ZIP file holds the folder and the extracted file opens. The deleted file is back in its folder from the Recycle Bin. Wrong wording: version history (simulated; it needs a service such as OneDrive or Google Docs). Missing file: the Recycle Bin or the service's recycle bin. Backup: a separate copy for when every synced copy is gone. A ZIP packages files; it is not encryption or a backup.

Review: Viewer meets the task with less ability to change the shared copy. It does not encrypt it.
