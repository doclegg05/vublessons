Read the explanation

Use a descriptive title, real heading styles, short sections and a list of steps. Bold alone does not create a heading for assistive technology.

Keyboard shortcuts with a purpose

Ctrl+C copies; Ctrl+V pastes; Ctrl+Z undoes; Ctrl+S saves. On a Mac, use Command. Practice selecting only the text you want to change.

Make one clear paragraph

State the service, who it helps and the next action. Read it aloud. Replace vague words with concrete instructions.

Track a proposed change

Turn on Track Changes or Suggesting in your editor. Make one edit. The reviewer accepts or rejects it; a comment can explain why.

Prepare a handout someone can read

Use real headings, readable type and meaningful link text. Add useful alternative text to informative images. Do not rely on color alone.

A workbook has rows, columns, and cells

A row can represent one item; a column can represent a category. Label the units. Keep numbers as numbers so formulas can calculate.

Build a fictional supply budget

Enter Paper: 12, Folders: 8, Pens: 5 in a cost column. In a total cell, use =SUM(B2:B4). The expected total is 25.

Read the explanation

Change the paper cost to 15. The total should become 28. If it does not, check the cell range and whether values were entered as text.

A chart answers a question

A bar chart can compare costs. Use a title and labels with units. Keep a readable data table so the numbers are available without interpreting color.

Three slides; one useful message

Slide 1: the need. Slide 2: the steps. Slide 3: where to get help. Use one consistent theme and enough contrast for the room.

Crop, resize, and preserve the original

Crop removes outer areas. Resize changes dimensions. Save a copy before editing. Do not stretch an image or remove a creator’s credit.

Basic video editing

Trim an unwanted start or end. Split to remove a middle section. Arrange clips, balance speech volume and add accurate captions. Check the exported result.

Reusing content requires permission

Check the license and its conditions. Credit the creator, title, source and license when required. An image appearing in search does not mean you may reuse it.

Read the explanation

An editable document supports revision. PDF preserves a finished layout. CSV carries simple table data but loses formatting and formulas.

Inspect the export

Open the exported file. Check headings, page breaks, links and missing content. Verify the filename and folder. The export is a separate artifact to test.
