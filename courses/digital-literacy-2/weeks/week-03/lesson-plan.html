Week 3 lesson plan: Create something people can use

Course home

Build a clear resource handout, a small workbook, and a short presentation.

Learning outcomes

  • Handout: in Word at a lab workstation, each learner types the given handout lines, applies Heading 1 and Heading 2 styles, makes the steps a numbered list, and confirms that both headings appear in the Navigation pane. All correct with no more than one prompt, and no heading made with bold alone.
  • Editing and review: in their own handout, each learner adds a link whose text names the destination (Ctrl and K), copies, pastes and undoes one phrase, and saves the file in the Resource pack folder; then, at a partner's seat, turns on Track Changes and makes one edit, and back at their own seat accepts or rejects the partner's edit with a stated reason.
  • Workbook: given supplies.csv in Excel, each learner types =SUM(B2:B4) in B5 and presses Enter, confirms 25, writes a prediction before changing paper to 15, confirms 28, and saves the file as an Excel workbook so the formula is kept. All steps correct with no more than one prompt.
  • Slides and media: in PowerPoint, each learner builds three slides (need, steps, help) with one theme, inserts the practice photo, crops it without changing the photo file, adds alt text that says what the photo shows and a credit line, and says in one sentence what trimming and splitting remove from a video clip.
  • Export: each learner saves the handout as a PDF in the Resource pack folder, opens it from File Explorer, checks the headings, numbered steps and link, and names the right format for a reader (PDF), a co-editor (Word document) and a tool that needs plain rows (CSV).

Prepare the room

Each station: Microsoft Word, Excel and PowerPoint that open without a sign-in, Microsoft Edge, headphones, and this lesson and worksheet. Before class, check that Word and Excel can save to Documents on This PC, not only OneDrive, and that Edge can download supplies.csv and the practice photo from the worksheet; if downloads are blocked, copy both files into Documents on each station. No account is needed: the tracked edit is done by swapping seats, and video editing is practiced on slide 14 because Clipchamp needs a Microsoft account. Nothing needs printing; learners may print the worksheet. At the front: Word, Excel and PowerPoint ready on the projector. Play video chapters 2 and 5 with captions to check sound, and practice the pause at 2:59. Keep a roster for the individual check. If this class falls on a federal holiday, confirm the building and lab are open. After your own run-through, delete your Resource pack folder and downloads, then select Start fresh on this computer at each station.

For unavailable features, use the course simulation or role play and label the evidence as simulated.

Lab quick card: Windows 11

Click-by-click steps for this week’s tasks in Windows 11 with Microsoft Edge. If your screen looks different, ask your instructor.

To do thisSteps
Make the Resource pack folderOpen File Explorer and go to Documents. Select New › Folder, type Resource pack and press Enter.
Save a file into Resource packFile › Save As › Browse. Open Documents › Resource pack, type the file name and select Save. After that, Ctrl and S saves your changes.
Apply a heading and check itSelect the line, then on the Home tab choose Heading 1 or Heading 2 in the Styles gallery. To check, select View › Navigation Pane (or press Ctrl and F) and look under Headings.
Make a numbered listSelect the lines, then select Home › Numbering.
Add a linkSelect the link text and press Ctrl and K (or Insert › Link). Type the web address in the Address box and select OK.
Copy, paste and undoSelect the words. Ctrl and C copies, Ctrl and V pastes, and Ctrl and Z undoes the last change.
Track a change, then decideReview › Track Changes (or Ctrl and Shift and E), then make your edit. To decide, select the change and choose Review › Accept or Reject.
Open supplies.csv in ExcelIn Edge, press Ctrl and J and select Open file under supplies.csv. Or in Excel: File › Open › Browse › Downloads, choose Text Files in the file-type list, and double-click supplies.csv.
Add a total with SUMClick B5. Type =SUM(B2:B4) and press Enter. Start with the equals sign, and type a colon between B2 and B4.
Keep the formula when you saveFile › Save As › Browse. In Save as type, choose Excel Workbook (*.xlsx), then select Save. Saving as CSV keeps only the values.
Start slides with one themeOpen PowerPoint and select Blank Presentation. On the Design tab, select a theme. Home › New Slide adds a slide.
Insert and crop a pictureInsert › Pictures › This Device, choose the photo and select Insert. Select Picture Format › Crop, drag the black handles inward, then press Esc.
Add alt textRight-click the picture and choose View Alt Text (or Picture Format › Alt Text). Type one or two sentences that say what the picture shows.
Save the handout as a PDFIn Word, File › Save a Copy (or Save As) › Browse. Open Resource pack, set Save as type to PDF and select Save. Double-click the PDF in File Explorer to open it.

Using the chaptered video

Play each chapter inside its cycle, as the Show, from the video slide. Pause at the times named in the plan; the narration does not stop by itself. Ask learners to predict before a demonstration and explain the evidence afterward. Replay only the chapter needed for a refresher.

Facilitation and access

Demonstrate slowly, then let learners try. Offer keyboard and mouse paths, captions and the written transcript. Print large copies if needed. Every learner works at their own workstation; a partner coaches but does not take over. Provide extra practice time without requiring learners to disclose a disability.

Evidence to collect

  • Who will read a computer-help handout, and what should they do after reading it? Write one sentence that names the reader and the next action.
  • In Word, open a blank document and type these lines, one per line: Computer help at the library / Who it helps / Anyone who wants to practice one computer task. / Steps / Choose one task. / Visit the learning desk. / Ask how to repeat it at home. Make the first line Heading 1, and Who it helps and Steps Heading 2 (Home › Styles). Select the three steps and choose Home › Numbering. Open View › Navigation Pane and check that both headings are listed.
  • Add a last line: Read the computer-help guide. Select it, press Ctrl and K, type https://example.org/help in the Address box and select OK. Select the words learning desk, press Ctrl and C, click at the end of the last line, press Ctrl and V, then Ctrl and Z to undo. Save the file as resource-handout in your Resource pack folder. Record the shortcut that helped most.
  • Swap seats with your partner. In their handout, select Review › Track Changes and change one word to make a step clearer. Swap back. Find your partner's change, select Review › Accept or Reject, and write your reason.
  • Download supplies.csv (button below) and open it in Excel. Type Total in A5. Click B5, type =SUM(B2:B4) and press Enter; B5 should show 25. Before you change anything, write what B5 will show if paper costs 15. Click B2, type 15 and press Enter, then check B5. Save with File › Save As as an Excel Workbook named supplies in your Resource pack folder.
  • In PowerPoint, choose Blank Presentation and pick one theme on the Design tab. Make three slides titled Need computer help? / Steps / Where to get help. Paste the three steps from your handout on slide 2, and type Visit the learning desk on slide 3. Check the words can be read from the back of the room. Save as resource-slides in your Resource pack folder.
  • Download the practice photo (button below). On slide 1, choose Insert › Pictures › This Device and insert it. Select Picture Format › Crop, drag the black handles in so the two people and the handout fill the picture, and press Esc. Right-click the photo, choose View Alt Text, and write one sentence about what it shows. Type this credit in the subtitle box: Photo: VUB practice photo, used with permission. Save.
  • In Word, save the handout as a PDF: File › Save a Copy (or Save As) › Browse, open Resource pack, set Save as type to PDF and select Save. Open Resource pack in File Explorer and double-click the PDF. Check the headings, numbered steps and link. Write which format fits a neighbor who only reads it, a partner who must edit it, and a tool that needs plain rows.

Feedback and differentiation

Ask the learner to explain a choice and demonstrate the result. Mark Independent, With prompt, or Needs practice. Re-model only the missing step. For faster learners, ask them to test an edge case or explain an alternative; do not add unrelated tasks.
