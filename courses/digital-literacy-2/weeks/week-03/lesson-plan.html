Week 3 · Lesson plan

Objectives

  • Give a handout real headings, numbered steps and a clear link.
  • Use shortcuts and Track Changes to edit safely and let the owner decide.
  • Add costs with a SUM formula and check that the total updates.
  • Make three matching slides with a cropped, described and credited photo.
  • Save a PDF, check it, and choose the right file type for the next person.

Observable outcomes

  • Handout: in Word at a lab workstation, each learner types the given handout lines, applies Heading 1 and Heading 2 styles, makes the steps a numbered list, and confirms that both headings appear in the Navigation pane. All correct with no more than one prompt, and no heading made with bold alone.
  • Editing and review: in their own handout, each learner adds a link whose text names the destination (Ctrl and K), copies, pastes and undoes one phrase, and saves the file in the Resource pack folder; then, at a partner's seat, turns on Track Changes and makes one edit, and back at their own seat accepts or rejects the partner's edit with a stated reason.
  • Workbook: given supplies.csv in Excel, each learner types =SUM(B2:B4) in B5 and presses Enter, confirms 25, writes a prediction before changing paper to 15, confirms 28, and saves the file as an Excel workbook so the formula is kept. All steps correct with no more than one prompt.
  • Slides and media: in PowerPoint, each learner builds three slides (need, steps, help) with one theme, inserts the practice photo, crops it without changing the photo file, adds alt text that says what the photo shows and a credit line, and says in one sentence what trimming and splitting remove from a video clip.
  • Export: each learner saves the handout as a PDF in the Resource pack folder, opens it from File Explorer, checks the headings, numbered steps and link, and names the right format for a reader (PDF), a co-editor (Word document) and a tool that needs plain rows (CSV).

Before class: print worksheet and answer guide; open the lesson and practice library; check projector, keyboard, sound and printer; provide fresh fictional files. The course video is available for optional chapter replay. No learner account or purchase is required.

Teaching rhythm

Tell: explain the purpose using prior experience. Show: ask for a prediction and demonstrate one step at a time. Do: learners act at their own seats using the quick card. Review: explain choices and inspect evidence. Use N for slide-specific instructor notes and the answer guide for expected results.

Pacing and recovery

Protect the 8-minute break. Finish each essential Point B before optional extensions. Offer prepared examples, partner observation and paper annotation when tools are unavailable; record these as simulated work. Use the closing block for consolidation, not a new task.

Week 3 is deliberately sequential: 27 minutes Word, 22 Excel, break, 20 PowerPoint, 16 export/media. Use the supplied starter wording and fresh CSV. Charts, extra decoration and advanced video editing are optional. If a learner falls behind, provide the completed prior artifact so the next objective can still be practiced.

Lab quick card: Windows 11

Make the Resource pack folder
Open File Explorer and go to Documents. Select New › Folder, type Resource pack and press Enter.
Save a file into Resource pack
File › Save As › Browse. Open Documents › Resource pack, type the file name and select Save. After that, Ctrl and S saves your changes.
Apply a heading and check it
Select the line, then on the Home tab choose Heading 1 or Heading 2 in the Styles gallery. To check, select View › Navigation Pane (or press Ctrl and F) and look under Headings.
Make a numbered list
Select the lines, then select Home › Numbering.
Add a link
Select the link text and press Ctrl and K (or Insert › Link). Type the web address in the Address box and select OK.
Copy, paste and undo
Select the words. Ctrl and C copies, Ctrl and V pastes, and Ctrl and Z undoes the last change.
Track a change, then decide
Review › Track Changes (or Ctrl and Shift and E), then make your edit. To decide, select the change and choose Review › Accept or Reject.
Open supplies.csv in Excel
In Edge, press Ctrl and J and select Open file under supplies.csv. Or in Excel: File › Open › Browse › Downloads, choose Text Files in the file-type list, and double-click supplies.csv.
Add a total with SUM
Click B5. Type =SUM(B2:B4) and press Enter. Start with the equals sign, and type a colon between B2 and B4.
Keep the formula when you save
File › Save As › Browse. In Save as type, choose Excel Workbook (*.xlsx), then select Save. Saving as CSV keeps only the values.
Start slides with one theme
Open PowerPoint and select Blank Presentation. On the Design tab, select a theme. Home › New Slide adds a slide.
Insert and crop a picture
Insert › Pictures › This Device, choose the photo and select Insert. Select Picture Format › Crop, drag the black handles inward, then press Esc.
Add alt text
Right-click the picture and choose View Alt Text (or Picture Format › Alt Text). Type one or two sentences that say what the picture shows.
Save the handout as a PDF
In Word, File › Save a Copy (or Save As) › Browse. Open Resource pack, set Save as type to PDF and select Save. Double-click the PDF in File Explorer to open it.

Week-specific preparation

Each station: Microsoft Word, Excel and PowerPoint that open without a sign-in, Microsoft Edge, headphones, and this lesson and worksheet. Before class, check that Word and Excel can save to Documents on This PC, not only OneDrive, and that Edge can download supplies.csv and the practice photo from the worksheet; if downloads are blocked, copy both files into Documents on each station. No account is needed: the tracked edit is done by swapping seats, and video editing is practiced on slide 14 because Clipchamp needs a Microsoft account. Nothing needs printing; learners may print the worksheet. At the front: Word, Excel and PowerPoint ready on the projector. Play video chapters 2 and 5 with captions to check sound, and practice the pause at 2:59. Keep a roster for the individual check. If this class falls on a federal holiday, confirm the building and lab are open. After your own run-through, delete your Resource pack folder and downloads, then select Start fresh on this computer at each station.
