Week 3 worksheet answer guide

Course home

Instructor guide. Accept equivalent evidence-based answers. These activities evaluate demonstrated skills, not speed.

1. Who will read a computer-help handout, and what should they do after reading it? Write one sentence that names the reader and the next action.

Names a specific reader (for example, a neighbor who wants computer help) and one next action (for example, visit the learning desk).

2. In Word, open a blank document and type these lines, one per line: Computer help at the library / Who it helps / Anyone who wants to practice one computer task. / Steps / Choose one task. / Visit the learning desk. / Ask how to repeat it at home. Make the first line Heading 1, and Who it helps and Steps Heading 2 (Home › Styles). Select the three steps and choose Home › Numbering. Open View › Navigation Pane and check that both headings are listed.

The first line uses Heading 1, and Who it helps and Steps use Heading 2, not bold; the three steps are numbered; both headings appear in the Navigation pane.

3. Add a last line: Read the computer-help guide. Select it, press Ctrl and K, type https://example.org/help in the Address box and select OK. Select the words learning desk, press Ctrl and C, click at the end of the last line, press Ctrl and V, then Ctrl and Z to undo. Save the file as resource-handout in your Resource pack folder. Record the shortcut that helped most.

The link text names the destination and the link opens; paste and undo worked with no lost text; resource-handout is in the Resource pack folder; one useful shortcut is named.

4. Swap seats with your partner. In their handout, select Review › Track Changes and change one word to make a step clearer. Swap back. Find your partner's change, select Review › Accept or Reject, and write your reason.

The edit appeared as a tracked change before the owner selected Accept or Reject; the reason names what the reader needs. Only the owner makes the final choice.

5. Download supplies.csv (button below) and open it in Excel. Type Total in A5. Click B5, type =SUM(B2:B4) and press Enter; B5 should show 25. Before you change anything, write what B5 will show if paper costs 15. Click B2, type 15 and press Enter, then check B5. Save with File › Save As as an Excel Workbook named supplies in your Resource pack folder.

B5 shows =SUM(B2:B4) in the formula bar and 25; a written prediction came before the change; B5 shows 28 after B2 becomes 15; saved as supplies.xlsx. Saving as CSV would keep the number but drop the formula.

6. In PowerPoint, choose Blank Presentation and pick one theme on the Design tab. Make three slides titled Need computer help? / Steps / Where to get help. Paste the three steps from your handout on slide 2, and type Visit the learning desk on slide 3. Check the words can be read from the back of the room. Save as resource-slides in your Resource pack folder.

Three slides in the order need, steps, help; one theme on all three; text readable from the back of the room; the steps match the handout.

7. Download the practice photo (button below). On slide 1, choose Insert › Pictures › This Device and insert it. Select Picture Format › Crop, drag the black handles in so the two people and the handout fill the picture, and press Esc. Right-click the photo, choose View Alt Text, and write one sentence about what it shows. Type this credit in the subtitle box: Photo: VUB practice photo, used with permission. Save.

The photo is cropped in PowerPoint and the photo file itself is unchanged; the alt text says in one sentence what the photo shows; the credit line names the source and the permission.

8. In Word, save the handout as a PDF: File › Save a Copy (or Save As) › Browse, open Resource pack, set Save as type to PDF and select Save. Open Resource pack in File Explorer and double-click the PDF. Check the headings, numbered steps and link. Write which format fits a neighbor who only reads it, a partner who must edit it, and a tool that needs plain rows.

The PDF is in Resource pack and opens; the checks name headings, steps and a working link; a reader gets the PDF, an editor the Word document, and a tool that needs rows gets CSV.
