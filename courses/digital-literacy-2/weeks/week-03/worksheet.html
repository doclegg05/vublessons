Mission 3A · Structure, then suggest

Point A

A wall of plain text

Point B

A clear handout with a reviewed edit

App: Word · Interactive practice

  1. Who will read a computer-help handout, and what should they do after reading it? Write one sentence that names the reader and the next action.
  2. In Word, open a blank document and type these lines, one per line: Computer help at the library / Who it helps / Anyone who wants to practice one computer task. / Steps / Choose one task. / Visit the learning desk. / Ask how to repeat it at home. Make the first line Heading 1, and Who it helps and Steps Heading 2 (Home › Styles). Select the three steps and choose Home › Numbering. Open View › Navigation Pane and check that both headings are listed.
  3. Add a last line: Read the computer-help guide. Select it, press Ctrl and K, type https://example.org/help in the Address box and select OK. Select the words learning desk, press Ctrl and C, click at the end of the last line, press Ctrl and V, then Ctrl and Z to undo. Save the file as resource-handout in your Resource pack folder. Record the shortcut that helped most.
  4. Swap seats with your partner. In their handout, select Review › Track Changes and change one word to make a step clearer. Swap back. Find your partner's change, select Review › Accept or Reject, and write your reason.

Route used: app / simulation / paper · Support: independent / with prompt / needs practice

Mission 3B · Make the total recalculate

Point A

Paper $12 + pens $8 + folders $5

Point B

A tested formula, saved as .xlsx

App: Excel · Interactive practice

  1. Download supplies.csv (button below) and open it in Excel. Type Total in A5. Click B5, type =SUM(B2:B4) and press Enter; B5 should show 25. Before you change anything, write what B5 will show if paper costs 15. Click B2, type 15 and press Enter, then check B5. Save with File › Save As as an Excel Workbook named supplies in your Resource pack folder.

Route used: app / simulation / paper · Support: independent / with prompt / needs practice

Mission 3C · Show the message clearly

Point A

An audience who needs computer help

Point B

Three matching slides and a useful photo

App: PowerPoint · Interactive practice

  1. In PowerPoint, choose Blank Presentation and pick one theme on the Design tab. Make three slides titled Need computer help? / Steps / Where to get help. Paste the three steps from your handout on practice library exercise 2, and type Visit the learning desk on practice library exercise 3. Check the words can be read from the back of the room. Save as resource-slides in your Resource pack folder.
  2. Download the practice photo (button below). On practice library exercise 1, choose Insert › Pictures › This Device and insert it. Select Picture Format › Crop, drag the black handles in so the two people and the handout fill the picture, and press Esc. Right-click the photo, choose View Alt Text, and write one sentence about what it shows. Type this credit in the subtitle box: Photo: VUB practice photo, used with permission. Save.

Mission 3D · Export, then inspect

Point A

A finished editable resource pack

Lab quick card: Windows 11

Make the Resource pack folder
Open File Explorer and go to Documents. Select New › Folder, type Resource pack and press Enter.
Save a file into Resource pack
File › Save As › Browse. Open Documents › Resource pack, type the file name and select Save. After that, Ctrl and S saves your changes.
Apply a heading and check it
Select the line, then on the Home tab choose Heading 1 or Heading 2 in the Styles gallery. To check, select View › Navigation Pane (or press Ctrl and F) and look under Headings.
Make a numbered list
Select the lines, then select Home › Numbering.
Add a link
Select the link text and press Ctrl and K (or Insert › Link). Type the web address in the Address box and select OK.
Copy, paste and undo
Select the words. Ctrl and C copies, Ctrl and V pastes, and Ctrl and Z undoes the last change.
Track a change, then decide
Review › Track Changes (or Ctrl and Shift and E), then make your edit. To decide, select the change and choose Review › Accept or Reject.
Open supplies.csv in Excel
In Edge, press Ctrl and J and select Open file under supplies.csv. Or in Excel: File › Open › Browse › Downloads, choose Text Files in the file-type list, and double-click supplies.csv.
Add a total with SUM
Click B5. Type =SUM(B2:B4) and press Enter. Start with the equals sign, and type a colon between B2 and B4.
Keep the formula when you save
File › Save As › Browse. In Save as type, choose Excel Workbook (*.xlsx), then select Save. Saving as CSV keeps only the values.
Start slides with one theme
Open PowerPoint and select Blank Presentation. On the Design tab, select a theme. Home › New Slide adds a slide.
Insert and crop a picture
Insert › Pictures › This Device, choose the photo and select Insert. Select Picture Format › Crop, drag the black handles inward, then press Esc.
Add alt text
Right-click the picture and choose View Alt Text (or Picture Format › Alt Text). Type one or two sentences that say what the picture shows.
Save the handout as a PDF
In Word, File › Save a Copy (or Save As) › Browse. Open Resource pack, set Save as type to PDF and select Save. Double-click the PDF in File Explorer to open it.
