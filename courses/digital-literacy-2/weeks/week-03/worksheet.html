Lab quick card: Windows 11

Make the Resource pack folder
Open File Explorer and go to Documents. Select New › Folder, type Resource pack and press Enter.
Save a file into Resource pack
File › Save As › Browse. Open Documents › Resource pack, type the file name and select Save. After that, Ctrl and S saves your changes.
Apply a heading and check it
Select the line, then on the Home tab choose Heading 1 or Heading 2 in the Styles gallery. To check, select View › Navigation Pane (or press Ctrl and F) and look under Headings.
Make a numbered list
Select the lines, then select Home › Numbering.
Add a link
Select the link text and press Ctrl and K (or Insert › Link). Type the web address in the Address box and select OK.
Copy, paste and undo
Select the words. Ctrl and C copies, Ctrl and V pastes, and Ctrl and Z undoes the last change.
Track a change, then decide
Review › Track Changes (or Ctrl and Shift and E), then make your edit. To decide, select the change and choose Review › Accept or Reject.
Open supplies.csv in Excel
In Edge, press Ctrl and J and select Open file under supplies.csv. Or in Excel: File › Open › Browse › Downloads, choose Text Files in the file-type list, and double-click supplies.csv.
Add a total with SUM
Click B5. Type =SUM(B2:B4) and press Enter. Start with the equals sign, and type a colon between B2 and B4.
Keep the formula when you save
File › Save As › Browse. In Save as type, choose Excel Workbook (*.xlsx), then select Save. Saving as CSV keeps only the values.
Start slides with one theme
Open PowerPoint and select Blank Presentation. On the Design tab, select a theme. Home › New Slide adds a slide.
Insert and crop a picture
Insert › Pictures › This Device, choose the photo and select Insert. Select Picture Format › Crop, drag the black handles inward, then press Esc.
Add alt text
Right-click the picture and choose View Alt Text (or Picture Format › Alt Text). Type one or two sentences that say what the picture shows.
Save the handout as a PDF
In Word, File › Save a Copy (or Save As) › Browse. Open Resource pack, set Save as type to PDF and select Save. Double-click the PDF in File Explorer to open it.
