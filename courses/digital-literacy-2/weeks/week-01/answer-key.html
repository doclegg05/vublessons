Model answers for the "Check yourself" lines on Missions 1A–1E, and the five Quick Check questions from the projected deck. Accept close paraphrases — these check understanding, not exact wording.

Check yourself — Missions 1A–1E

MissionModel answer
1ABrowser zoom changes web pages only. Display Scale changes every app. To fix every app, I use Display Scale.
1BSound goes to one output (device) at a time. Before a video visit, I check the sound output.
1CBefore printing many copies, I print one test copy. The pager should say 1 of 1.
1DTo fix every future reminder I edit the series. I proved it worked by checking the next week's event.

Quick Check — projected review slides

UnitQuestionAnswer
ABrowser zoom fixed one website. What fixes every app?Display Scale in Settings ▸ System ▸ Display. Scale resizes Windows and every app; browser zoom only resizes web pages.
BVideo call sound comes from the speakers, not your headset. Check first?The sound output device: speaker icon ▸ › ▸ Headphones. Windows sends sound to one output at a time.
CThe preview shows page 2 with one line. First move?Adjust the layout (margins), then check the preview again — keep every word, print only once it fits.
DA repeating reminder shows up on the wrong day. Fix?Open it and edit the whole series, then check the next one — editing one occurrence leaves every future one wrong.
EWhich request gets the fastest answer — A, B, or C?B: app + version, what you did, what you tried, the exact message.
