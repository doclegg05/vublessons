Read the explanation

Choose the correct speaker or headset before adjusting volume. Brightness changes light output; contrast changes separation between light and dark.

Browser choices belong to you

Review the home page, downloads location and site permissions in Settings. A helpful default should fit your task. Restore shared-lab settings before leaving.

Processing, storage, and connections

The processor carries out instructions. Memory holds current work. Storage keeps files. A matching connector shape alone does not guarantee every feature.

Match a connection to its job

Select each card to reveal a useful connection. Read the device label before buying or plugging in a cable.

Printer choices

Laser printers use toner; inkjet printers use liquid ink. Choose for the task and running cost. A default printer is the device an app initially selects.

Print one page before twenty

Check the printer name and connection. Open print preview. Select one page, orientation and copies. Send a test page and check the output.

Read the explanation

Use day view for detail, week view for conflicts and month view for the larger picture. A task can have a due date without reserving meeting time.

Automation still needs a check

A rule can sort mail or repeat a reminder. Autocorrect changes likely mistakes; autocomplete suggests the rest. Review names, addresses and meaning before accepting.

Cloud services use another computer

Online storage and web apps use a provider’s computers over a network. Check account, connection and save status when you switch devices.
