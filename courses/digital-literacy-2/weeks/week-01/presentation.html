WK-01 // UNIT E // HELP REQUESTMicrosoft Word new blank document

A help request that gets answered

  1. 01App + version: File ▸ Account ▸ About
  2. 02What you were doing
  3. 03What you already tried
  4. 04The exact message, word for word

✗ Hard to help

“Word is broken. Help!”

✓ Easy to help

“Word (Microsoft 365, Version 2408): when I click Save I see ‘Document not saved.’ I restarted Word and tried Save As.”
