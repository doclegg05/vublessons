Instructor guide and lesson plans

Course home

The syllabus and six lesson plans cover the same six-week course. Week 1 uses the Mission Control deck and Missions 1A–1E. Each plan totals 120 minutes. Dates appear only on the cohort syllabus.

Before the course

For Week 1, open the slides at #1 and press F for fullscreen. Use the six phase buttons to jump, arrows to reveal and advance, and N for notes. For weeks 2–6, press P (or select Present on a projector). Slides fill the screen; a slide too tall for it shows its words first, then each visual, as you press Next. Press Esc to stop. Test playback, captions, print preview, software access and the lab printer. Provide fictional files and a demonstration account if collaboration features require sign-in. Rehearse the week 6 agent demo and open the three practice pages (versions 1, 2 and 3). Keep learner responses out of public repositories.

Practical scoring

Record task performance as Independent, With prompt or Needs practice. Use the worksheet answer guides for expected evidence. Keep practical observations separate from the 20-point knowledge score. Use the final worksheet’s 8-point app rubric for the extension.

Collecting the 20-question assessments

Learners enter their full name, answer 20 questions, review, and select Submit my test then Yes, submit. Grading runs in the browser; the results PDF downloads separately. The submission includes the learner name, record ID, test version, start and finish times, score, domain totals and answer letters. Pre/post use different scenarios with the same skills and domain counts.

Open VUB’s Netlify Forms dashboard and choose dl2-pretest or dl2-posttest to view or export records. Form email notifications are configured for britt.legg76@gmail.com. Netlify receipt means the platform accepted the copy; it does not prove that an email reached the inbox. Match each record ID to the learner’s PDF. If a retry creates duplicate rows with the same record ID, count the record only once.

If the page says the copy is queued, keep that browser’s data and reopen the test when online; it retries automatically. Ask the learner to save or print the PDF as a backup. If local storage is unavailable, collect that PDF yourself. A queued copy has not reached Netlify yet.

Flash-drive backup

Supply each learner with a USB flash drive. After grading, the learner selects Download graded PDF. If Save As appears, choose that drive; otherwise copy the downloaded PDF from Downloads to the drive. The filename includes test type, surname, date, time and a unique record suffix to avoid overwriting another learner’s file. Have the learner open the PDF from the drive, check name, test type and score, close it, safely eject and return the drive. Keep the PDF even if Netlify is temporarily unavailable. Downloading does not submit results, and submitting does not copy the PDF to the drive.

Shared computers and clearing

Test drafts persist in this browser until submission or Start over. Check the displayed name before resuming. Lesson progress also stays in this browser. After saving results, select Start fresh on this computer on the course home; this clears lesson progress and test drafts but keeps unsent copies for retry. Keep student PDFs, notification emails and exported records in instructor-controlled storage, outside the public website.
