Assessment version 2 · Fictional practice scenarios

Name or learner code: ____________________

Read each situation and choose the one answer that best fits the task. Each correct answer earns one point. Total: 28. This is a classroom assessment, not a certification exam.

1. At your local library, the text on a computer-help webpage is too small. Text in your other apps is comfortable to read. Which change best fits this problem?

  1. ☐ Increase the browser zoom for the webpage.
  2. ☐ Increase display scaling for the whole computer.
  3. ☐ Increase screen brightness without changing text size.

2. A library volunteer is arranging a practice session with you. They need to see when you are busy, but you want to keep appointment names and locations private. Which calendar setting best fits?

  1. ☐ Share event titles and locations with the volunteer.
  2. ☐ Publish the full calendar for anyone with the link.
  3. ☐ Share free/busy availability only.

3. While you draft a message about a library visit, autocorrect replaces your neighbor’s last name with a different word. The changed word is spelled correctly. What should you do before sending?

  1. ☐ Rely on the recipient to work out which name you meant.
  2. ☐ Restore the intended name and reread the message.
  3. ☐ Keep the change because the spelling checker accepts it.

4. You need 20 copies of a one-page computer-help handout. The lab has two printers, and the print dialog shows the one used yesterday. What should you do before printing the full set?

  1. ☐ Confirm the printer, inspect the preview and print one test copy.
  2. ☐ Send 20 copies to the printer already selected in the dialog.
  3. ☐ Send one copy to each printer, then use whichever finishes first.

5. You use a personal account and a separate volunteer account. Before posting a library event notice, you notice your personal account is active. The notice should come from the volunteer account. What should you do?

  1. ☐ Post from the personal account and sign the volunteer group’s name.
  2. ☐ Keep the personal account active and change only its profile photo.
  3. ☐ Switch accounts and check the posting identity and audience.

6. It is late at night, and you finish a nonurgent request for a library volunteer. You need a reply by Friday, and the group normally handles messages during daytime hours. Which approach is most considerate?

  1. ☐ Ask for an immediate reply without mentioning the Friday deadline.
  2. ☐ Send during expected hours and state that a reply is needed by Friday.
  3. ☐ Mark the message urgent so it gets attention tonight.

7. During a library practice session, a partner asks what an abbreviation in your instructions means. You do not know their past computer experience. Which response best helps them continue?

  1. ☐ Explain the term in plain language and ask whether an example would help.
  2. ☐ Repeat the abbreviation more slowly without explaining it.
  3. ☐ Take over the task because their question shows they cannot do it.

8. You want to change an app’s download folder, but its menus changed after an update. An older printed guide shows a button you cannot find. What is the most useful next step?

  1. ☐ Keep looking only for the old button shown in the printed guide.
  2. ☐ Install an unfamiliar repair tool that promises to restore all old menus.
  3. ☐ Use official help for the current version and search for changing the download folder.

9. You want an in-person computer-help session at a public library near Beckley, West Virginia. Which search gives the search engine the clearest description of your need?

  1. ☐ West Virginia community activities
  2. ☐ Beckley WV public library computer help sessions
  3. ☐ computer help anywhere online

10. A shared post says every library in your county offers free laptop loans. It gives no source or date. You want to borrow a laptop from your local library. What is the best way to check the claim?

  1. ☐ Contact that library through its official website or known phone number.
  2. ☐ Treat the number of shares as proof that the offer is available.
  3. ☐ Rely on another directory that repeats the same unsourced claim.

11. You need computer help you can attend locally in West Virginia. You find a current, accurate library page, but the class is in another state and is in person only. Why does this page not meet your need?

  1. ☐ Any page about a library must apply to your local library too.
  2. ☐ A current page is enough to show that the class is available nearby.
  3. ☐ The information can be accurate but not relevant to your location.

12. In the fictional library practice form, you need to request computer help. The form has required fields and several optional fields. What should you check before entering information?

  1. ☐ Whether entering extra private details will move the request ahead of others.
  2. ☐ Who receives it, why it is needed and which fields the request requires.
  3. ☐ How to fill every optional field, even when it adds unrelated details.

13. You are making a library handout with sections called Getting started, Practice steps and Where to get help. Readers should be able to navigate its sections, including with a screen reader. How should you mark the section titles?

  1. ☐ Apply the document’s appropriate heading styles.
  2. ☐ Make the titles bold but leave them as ordinary paragraphs.
  3. ☐ Insert extra blank lines above each title without using headings.

14. Your practice budget lists paper at $12 in B2, folders at $8 in B3 and pens at $5 in B4. You want a total that updates if any cost changes. Which formula belongs in the total cell?

  1. ☐ =B2+B4
  2. ☐ =25
  3. ☐ =SUM(B2:B4)

15. You find a photograph through an image search and want to add it to a community handout. The search preview does not show reuse terms. What should you do before using it?

  1. ☐ Use it without checking because the handout will be given away free.
  2. ☐ Open the source, check allowed uses and follow any required credit conditions.
  3. ☐ Use it with the creator’s name because credit alone always grants permission.

16. A partner needs to rewrite two paragraphs in your workshop handout. You want them to edit the wording directly. Which file and access best support that task?

  1. ☐ An editable document with permission for the partner to edit.
  2. ☐ A picture of the page that lets the partner see the wording.
  3. ☐ An editable document shared with view-only permission.

17. You are emailing the library to ask which room will host its computer-help session. Which subject line best tells the recipient what you need?

  1. ☐ A question about something at the library
  2. ☐ Computer-help session room confirmed
  3. ☐ Please confirm the room for the computer-help session

18. You are sending a workshop announcement to people who do not need to see one another’s email addresses. Which choice hides that recipient list from the other recipients?

  1. ☐ Place all those addresses in To.
  2. ☐ Place those addresses in Bcc.
  3. ☐ Place those addresses in Cc.

19. A fictional design app offers a seven-day free trial for making a community flyer. You only need it for one project. What should you check before starting the trial?

  1. ☐ Whether it renews, what it will cost and how and when to cancel.
  2. ☐ Only whether the first seven days are free.
  3. ☐ Only whether deleting the app removes it from the computer.

20. You downloaded a fictional photo app for free. A new button offers extra templates for a one-time $4 charge. What should you do before choosing that upgrade?

  1. ☐ Assume the templates are free because the app cost nothing to download.
  2. ☐ Approve the purchase first and check what it costs afterward.
  3. ☐ Review the separate purchase and its terms before deciding whether to authorize it.

21. Two library volunteers open the same shared handout during a live call. Both edit it while discussing their changes. Which description fits the way they are working?

  1. ☐ Independent copies: each person edits a separate file.
  2. ☐ Synchronous collaboration: working together at the same time.
  3. ☐ Asynchronous collaboration: leaving work for someone to review later.

22. Your library handout needs a partner’s feedback. They should leave comments, but you will make the wording changes. The sharing tool offers Viewer, Commenter and Editor. Which access best fits?

  1. ☐ Commenter for the named partner.
  2. ☐ Viewer for the named partner.
  3. ☐ Editor for anyone with the link.

23. A partner’s computer-help handout says “contact us” but gives no phone number or other contact method. Which comment best explains a useful revision?

  1. ☐ Make the handout better before we share it.
  2. ☐ Change the title color; that should solve the missing contact information.
  3. ☐ Add a contact method after the steps so readers know how to get help.

24. You want to record an online volunteer meeting so an absent partner can review it. Participants will be visible and speaking. What should happen before you start recording?

  1. ☐ Start recording because the meeting software offers a Record button.
  2. ☐ Check the organizer’s rules and obtain the appropriate recording permission.
  3. ☐ Assume joining the meeting means everyone agreed to be recorded.

25. One learner uses a keyboard instead of a mouse. Another needs captions to follow spoken directions. Which version of a library learning page supports both needs?

  1. ☐ A page with keyboard-operated controls and captioned videos.
  2. ☐ A page with captions but controls that require a mouse.
  3. ☐ A page with keyboard controls but spoken directions available only as audio.

26. In a fictional online group, a new contact quickly becomes friendly, claims to be a local volunteer and asks for private information. You have not verified their identity. What is the best response?

  1. ☐ Trust the request because the profile includes local photos.
  2. ☐ Ask the same contact to promise the profile is real, then send the information.
  3. ☐ Pause the request and verify their identity through a separate trusted route.

27. You find an unknown USB drive beside a computer in the library lab. You would like to return it to its owner. What is the safest next step?

  1. ☐ Try it on your own laptop so the shared lab computer is not affected.
  2. ☐ Give it to the instructor or authorized staff without connecting it.
  3. ☐ Plug it into a lab computer to look for the owner’s name.

28. A practice file can still be read even after you mark it read-only. You want to protect its readable contents if someone gets a copy without the needed key. Which feature addresses that goal?

  1. ☐ Encryption of the file’s contents.
  2. ☐ Read-only settings that restrict editing.
  3. ☐ A ZIP archive created without encryption.
