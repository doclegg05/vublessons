Pre-test printable assessment

Course home

Name or learner code: ____________________

Choose one answer per question. Each correct answer earns one point. Total: 28. This is a classroom assessment, not a certification exam.

1. A webpage is difficult to read, but other apps look fine. Which adjustment best fits?

  1. ☐ Increase browser zoom
  2. ☐ Change the default printer
  3. ☐ Rename the Downloads folder

2. A partner needs your availability, but not appointment details. Which calendar share fits?

  1. ☐ All private event notes
  2. ☐ Your account password
  3. ☐ Free/busy availability

3. Autocorrect changes a person’s name in your message. What should you do?

  1. ☐ Disable every security setting
  2. ☐ Review and correct the name before sending
  3. ☐ Assume the suggestion is always correct

4. Before printing 20 copies, what is the most useful check?

  1. ☐ Confirm the printer and preview one test page
  2. ☐ Select every available printer
  3. ☐ Change the computer’s wallpaper

5. You manage personal and volunteer accounts. What is a sensible practice?

  1. ☐ Reuse one password everywhere
  2. ☐ Post every message from whichever account opens
  3. ☐ Check the active account and use separate credentials

6. A nonurgent work message is ready late at night. What should guide when you send it?

  1. ☐ The size of your monitor
  2. ☐ Recipient expectations, urgency and working hours
  3. ☐ How many emojis are in it

7. Which wording best respects different levels of experience?

  1. ☐ Here are the steps; tell me where more detail would help.
  2. ☐ Everyone your age struggles with this.
  3. ☐ This is obvious, so do not ask questions.

8. An app feature has changed. What is a useful learning response?

  1. ☐ Assume all old instructions still apply
  2. ☐ Give up without identifying the task
  3. ☐ Check official help for your version and try the steps

9. You need a nearby library computer class. Which search is most useful?

  1. ☐ Every website
  2. ☐ Library computer class plus your town
  3. ☐ Interesting things

10. A post claims a community service is available everywhere. How should you check it?

  1. ☐ Verify with the responsible organization
  2. ☐ Trust it because it is first in search
  3. ☐ Count how many colors the page uses

11. An accurate page describes a service in another state. Why might it be unsuitable?

  1. ☐ Accurate pages are never useful
  2. ☐ Every government page applies everywhere
  3. ☐ It may not be relevant to your local need

12. Before submitting an online form, what should you check?

  1. ☐ Whether you can enter extra private details
  2. ☐ Who collects the data, required fields and the confirmation
  3. ☐ Only its background color

13. Which feature creates a document structure useful to readers and assistive technology?

  1. ☐ Heading styles
  2. ☐ Random blank lines
  3. ☐ Making every line bold

14. B2, B3 and B4 contain costs. Which formula totals all three?

  1. ☐ =B2+B4
  2. ☐ =SUM(A1:A2)
  3. ☐ =SUM(B2:B4)

15. You find an image online for a handout. What should you do before reusing it?

  1. ☐ Remove the creator’s name
  2. ☐ Check permission or license and provide required credit
  3. ☐ Assume search results are free to reuse

16. A partner needs to revise your paragraphs. Which format best fits?

  1. ☐ An editable document with appropriate access
  2. ☐ Only a photograph of the page
  3. ☐ An audio recording with no text

17. Which email subject best supports a clear request?

  1. ☐ Hi
  2. ☐ Important stuff
  3. ☐ Question about computer-help session location

18. What does Bcc do in an email?

  1. ☐ Verifies every recipient’s identity
  2. ☐ Hides Bcc recipient addresses from other recipients
  3. ☐ Encrypts all message content

19. Before starting a free app trial, what should you inspect?

  1. ☐ Renewal price, timing and cancellation terms
  2. ☐ Only the download button
  3. ☐ Only how many icons appear

20. A free game offers an in-app upgrade. What should you remember?

  1. ☐ Everything inside a free app is always free
  2. ☐ Payment screens never need review
  3. ☐ The upgrade may charge money even though the app was free

21. Two people edit a shared document together at the same time. What is this?

  1. ☐ Offline archiving
  2. ☐ Synchronous collaboration
  3. ☐ A private backup

22. A reviewer should suggest wording but not directly rewrite the file. Which access fits when supported?

  1. ☐ Commenter
  2. ☐ Public editor for everyone
  3. ☐ No access at all

23. Which feedback is most useful?

  1. ☐ Bad work.
  2. ☐ Change everything somehow.
  3. ☐ Add a contact number after the steps so readers can find help.

24. Before recording a class video meeting, what should you do?

  1. ☐ Assume joining is always recording consent
  2. ☐ Ask permission and follow the group’s rules
  3. ☐ Record secretly

25. What is an example of universal design?

  1. ☐ Controls usable by keyboard as well as mouse
  2. ☐ Instructions available only through color
  3. ☐ Very small fixed-size text

26. An online contact uses a false identity to build trust. What is this commonly called?

  1. ☐ File versioning
  2. ☐ Autocomplete
  3. ☐ Catfishing

27. You find an unknown USB drive in the lab. What should you do?

  1. ☐ Copy it to every computer
  2. ☐ Give it to authorized staff without plugging it in
  3. ☐ Open it to find the owner

28. What is the purpose of encryption?

  1. ☐ Make data unreadable without the appropriate key
  2. ☐ Make every website honest
  3. ☐ Reduce all files to half their size
