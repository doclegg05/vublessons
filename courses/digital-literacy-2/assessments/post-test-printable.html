Name or learner code: ____________________

Choose one answer per question. Each correct answer earns one point. Total: 28. This is a classroom assessment, not a certification exam.

1. The text on a service website is too small. What should you try first?

  1. ☐ Buy more online storage
  2. ☐ Change the email signature
  3. ☐ Use the browser’s zoom control

2. A volunteer scheduler only needs to know when you are unavailable. What should you share?

  1. ☐ Your recovery codes
  2. ☐ Free/busy information
  3. ☐ Every event description

3. Autocomplete suggests the wrong email address. What is the best response?

  1. ☐ Check and choose the intended address
  2. ☐ Send it because the app suggested it
  3. ☐ Share your password with both people

4. A handout is going to a shared lab printer. What should you verify first?

  1. ☐ The number of browser bookmarks
  2. ☐ Whether the email inbox is empty
  3. ☐ Printer destination, preview and a test page

5. Before posting in a professional group, what should you check?

  1. ☐ Whether your personal posts are entertaining
  2. ☐ The active identity, audience and account credentials
  3. ☐ Only the screen brightness

6. You need feedback next week. What is a considerate communication choice?

  1. ☐ State the deadline and respect expected working hours
  2. ☐ Demand an immediate reply at any hour
  3. ☐ Send the same message every five minutes

7. A new teammate does not know an abbreviation. What should you do?

  1. ☐ Assume their age explains the problem
  2. ☐ Exclude them from the task
  3. ☐ Explain it plainly without making assumptions

8. You cannot find a command in an updated app. What is the best next step?

  1. ☐ Share your password in a public forum
  2. ☐ Use current official help and describe the exact task
  3. ☐ Download the first unfamiliar fix offered

9. You need local public-library opening hours. Which query best fits?

  1. ☐ Library name, town and opening hours
  2. ☐ Libraries everywhere
  3. ☐ Good places

10. A directory promises a local service without naming a source. What is the best check?

  1. ☐ Assume a polished design proves the claim
  2. ☐ Share the claim before checking
  3. ☐ Confirm availability through the provider’s official contact

11. A reliable article explains an old program that no longer operates locally. What is the problem?

  1. ☐ A readable font guarantees relevance
  2. ☐ It may be outdated or irrelevant to this task
  3. ☐ Its accuracy proves current availability

12. A service-request form asks for information unrelated to the request. What should you do?

  1. ☐ Check the purpose and collector before providing it
  2. ☐ Fill every field with real private information
  3. ☐ Assume all forms have the same rules

13. How should you mark a document’s main sections?

  1. ☐ Add only larger spaces
  2. ☐ Turn the entire document into an image
  3. ☐ Apply appropriate heading styles

14. C2, C3 and C4 contain quantities. Which formula totals that range?

  1. ☐ =SUM(B1:B2)
  2. ☐ =SUM(C2:C4)
  3. ☐ =C2+C4

15. You want to adapt someone else’s diagram. What is the right first step?

  1. ☐ Check allowed uses and attribution conditions
  2. ☐ Use it without credit if it is small
  3. ☐ Assume a screenshot avoids all restrictions

16. A coauthor must change wording in your handout. What should you provide?

  1. ☐ Only a locked screenshot
  2. ☐ A filename without the file
  3. ☐ The editable file with suitable permissions

17. Which subject best helps a recipient act on a schedule question?

  1. ☐ Read this now!!!
  2. ☐ Please confirm the resource workshop start time
  3. ☐ Message

18. You use Bcc for an announcement. What protection does it provide?

  1. ☐ Conceals that recipient list from other recipients
  2. ☐ Guarantees the message cannot be forwarded
  3. ☐ Makes an attachment malware-free

19. A streaming offer starts at no charge. What should you check before accepting?

  1. ☐ Whether its logo is familiar
  2. ☐ Whether it plays an animation
  3. ☐ Whether it renews, the price and how to cancel

20. A downloaded app offers extra features for purchase. What is a sensible step?

  1. ☐ Share a payment password with the group
  2. ☐ Review the charge and purchase controls before authorizing
  3. ☐ Approve automatically because downloading was free

21. A team coauthors a file during a live call. Which description fits?

  1. ☐ Synchronous collaboration
  2. ☐ Asynchronous-only feedback
  3. ☐ File compression

22. A partner only needs to leave feedback on your draft. Which permission is appropriate when available?

  1. ☐ Unrestricted editing by anyone with the link
  2. ☐ Your account password
  3. ☐ Commenter access

23. Which comment best helps improve a shared handout?

  1. ☐ You never do this right.
  2. ☐ Define this abbreviation so a new reader can follow the instructions.
  3. ☐ I do not like it.

24. You want to save a webinar discussion that includes participants. What should guide your decision?

  1. ☐ Organizer rules and appropriate recording permission
  2. ☐ Whether the record button is easy to find
  3. ☐ Only how much storage you have

25. Which feature helps people use technology in different situations?

  1. ☐ A mouse-only form
  2. ☐ Audio-only directions without text
  3. ☐ Captions and flexible input methods

26. Someone invents a personal profile to manipulate a relationship. Which term fits?

  1. ☐ Compression
  2. ☐ Catfishing
  3. ☐ Cloud syncing

27. A stranger offers a USB drive with a useful app. What is the safest class response?

  1. ☐ Do not connect it; consult authorized support
  2. ☐ Run it immediately
  3. ☐ Disable protections to open it

28. An encrypted device is lost while powered off. What does encryption help protect?

  1. ☐ The truth of all messages ever received
  2. ☐ The ability to cancel every subscription
  3. ☐ The readability of stored data without its key
