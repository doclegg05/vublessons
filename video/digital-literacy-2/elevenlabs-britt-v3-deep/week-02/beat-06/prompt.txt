Think of a folder as a labeled place to put related work. Create a practice folder for the community resource task and use a descriptive file name, such as library-help-draft. A file saved on this computer may not appear on another computer. [short pause] A cloud file belongs to a service and an account, and a synced folder may keep copies in more than one place. Before moving to another device, check the account and the saving or syncing status. Reopen the file from the intended location. That simple test catches a common mistake: editing one copy while later opening an older copy somewhere else.
