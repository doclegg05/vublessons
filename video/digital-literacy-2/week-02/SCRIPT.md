## Know where the file lives
A file on this computer may not be available on another computer. A cloud service stores a copy under an account. Before switching devices, check that the latest changes have finished saving or syncing, and confirm which account owns or controls the file.

## Permission follows the task
Choose the smallest permission that lets the other person do the task. A viewer reads. A commenter can suggest wording when the service supports comments. An editor can change the content. Check the recipient carefully, then ask them to verify that the file opens.

## Sync is not a separate backup
Sync carries changes between a device and an online service. It may also carry a deletion. That is why sync alone is not a separate backup. A backup is another recovery copy, and version history may help you recover earlier content when the service supports it.

## Match the recovery tool
If the whole file was deleted, check the trash or recycle bin. If the file is still there but its content changed, inspect version history. Preview the earlier version before restoring it, and coordinate with collaborators so you do not overwrite work they need.
