Twenty multiple-choice questions, one per screen, in big type with big answer buttons. There's a review screen before submitting that flags anything skipped. Submitting grades the test and saves a PDF with your letterhead. The post-test covers the same skills in the same order with new scenarios, so the scores compare fairly.
