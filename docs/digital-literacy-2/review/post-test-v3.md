# Distinct post-test: version 3

The version 2 pre-test is unchanged in full: stems, options, answer positions, metadata and explanations. All 28 post-test items and their explanations are new. They test application, diagnosis and interpretation within the same taught objective groups. They are not the pre-test with town names or numbers substituted.

Both forms retain four items in each of seven domains and the same 28-point scale. Question pairs match objective groups, not necessarily the same narrow subskill. Different items can differ in difficulty; scores guide classroom practice and are not a standardized gain measure. No local service availability is asserted. Week 6 remains outside this knowledge score.

## Stored results and comparison

The pre-test keeps version 2 and its current session-storage key. The new post-test uses version 3 with a separate key, so old post answers cannot be applied to different questions. Existing version 2 pre-test results remain available. The comparison explicitly identifies the version 2 pre-test/version 3 post-test pairing. Earlier post reports remain historical records and should not be compared as if they used the new form.

All three post-test pages (browser, paper and answer key) are generated with version 3. Pre-test pages are unchanged. The answer bank still comes from `author-assessments.py`; feedback is now specific to each form.
