# Assessment version 2: scenario revision

All 56 questions now name a situation, the learner’s goal and one decision. The 28 pre/post pairs retain seven domains, four questions each and one point per item. Options address plausible misunderstandings rather than unrelated distractions. Feedback explains the principle and relevant limitations.

West Virginia library, home and volunteer settings are fictional. Town names provide search context without asserting that a service exists. No local knowledge, real account, purchase or personal information is required. Week 6 remains a separate practical rubric.

## Version and delivery

Browser drafts use a separate version 2 session-storage key. Old version 1 drafts are not loaded or regraded with new wording and are not deleted by this revision. The browser, paper copies, answer keys and saved graded results identify version 2. The post-test asks for a version 2 pre-score only; an earlier report should not be used for a direct gain comparison.

`author-assessments.py` is the content source. Run it before `build-pages.py` so browser data, paper copies and answer explanations stay aligned. No curriculum dates, topics, score totals or results branding changed.

## Validation

Targeted assessment/course checks: 39 passed, including both perfect and partial grading, saved drafts, old-version isolation, printed question/answer parity, offline results, keyboard navigation and enlarged mobile text. The full repository quality gate passes all 81 browser tests, build, links, catalog and accessibility ratchet. Both sample graded reports print to 11 pages with intact question/answer sections; every page was visually reviewed. Desktop/mobile captures and sample PDFs are in `assessment-v2/`.
