# DL2 objectives map: what each week must teach for the post-test (2026-09-27)

One page, for planning each week backwards from the test. The post-test (version 3) has 28 items,
four per IC3 GS6 domain, one point each, no pass mark. Every item is tagged to a week 1–5; nothing
tests week 6. Item numbers below are post-test items unless marked "pre". Source:
`scripts/dl2/author-assessments.py` (`q(domain, week, objective, ...)`).

**Rule for a rebuilt week:** each objective is one teaching unit (pose the problem → Tell → Show →
Do → Review), it names the item(s) it serves, and the units are the single source for the slides,
the run sheet and the lesson plan. Week 1 is the model (`W1_UNITS` in `scripts/dl2/author-content.py`).
